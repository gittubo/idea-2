design system

Clean scrapbook

Paper, tape and stickers, one bold ink colour, and plenty of white space so it stays easy to read. Every value below is a token at the top of styles.css, so a colour or size changes everywhere in one edit, including all the guides.

Colour

One bold colour, cobalt, does all the talking: buttons, links, scribbles, numbers. The tints are only for paper, tape and stickers, never for text.

Contrast (WCAG AA needs 4.5:1): cobalt on paper 6.7:1, white on cobalt 6.8:1, ink-2 on paper 9.2:1, ink-3 on paper 5.1:1, ink on butter 13.6:1.
