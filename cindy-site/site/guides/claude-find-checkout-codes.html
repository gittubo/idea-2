the setup

What this actually does

Claude in Chrome is Anthropic's browser extension. It can "see what you're looking at, click buttons, and fill forms" on the real tab you're on, so it can genuinely open a store, add an item to the cart, and type codes into the promo field like you would. Source: Claude for Chrome announcement.

The reason this is safe for a shopping task is the part most people miss. Claude in Chrome is completely blocked from "making purchases or financial transactions" and from "handling sensitive credit card or ID data." Source: Claude in Chrome permissions guide. So it can find and TEST codes for you, but it physically cannot complete the payment. You always press pay yourself.

before you start

Before you start

🔌 Get the extension. Install "Claude for Chrome" from the Chrome Web Store, sign in with your Claude account, and pin it. It's available on all paid Claude plans (Pro, Max, Team, Enterprise). Source: Get started with Claude in Chrome.
🖼️ Have your item ready. A screenshot of the product, or the product page open in a tab. A screenshot works great because Claude can read the item and brand straight off the image.
🏬 Pick the right kind of store. This works best on stores with a visible "promo code" or "discount code" box at checkout. If a store has no code field, there's nothing to test.
🔒 Keep checkout control. Let Claude test the promo field, then review the total and press the final purchase button yourself. Never hand payment details or an unsupervised checkout to the browser agent.
copy this

The exact prompt to paste

Open the Claude side panel on the shopping tab, drop in your item screenshot, and paste this:

🛒 the code-hunting prompt 
Here's the item I want to buy (screenshot attached). Please:
1. Open the store and add this exact item to my cart.
2. Search the web for current, real discount codes for this store and item (site-wide codes, first-order codes, seasonal sales). List the ones you find.
3. At checkout, enter each code into the promo/discount box one at a time and tell me which ones the site actually accepts, and the new total for each.
4. Apply the best working code and screenshot the cart showing the discount line and the lower total.
5. Stop before payment. Do not enter any card details or place the order. I'll do the final pay step myself.
Ask me before doing anything on a new site.

Then click to give Claude control of the tab and let it work. It reads the product, searches for live codes, types them into the promo box one by one, and watches which one the site accepts. When one sticks, it screenshots the lower total so you can see the discount landed before you pay.

keep it safe

The two permission settings that keep it in its lane

This is the part worth getting right, so Claude never clicks anything you didn't approve.

  1. 🚦 Pick "Ask before acting" mode. Claude in Chrome has two modes: "Ask before acting" (it pauses for your approval before each action) and "Act without asking" (it runs on its own, only pausing for unsafe-looking actions). For shopping, use "Ask before acting" so you approve each step. Source: permissions guide.
  2. 🌐 Grant access per site, not everywhere. When Claude asks to act on a store, choose "Allow this action" for a one-off, or "Always allow actions on this site" if you shop there often. You can review and revoke any site any time: click the Claude extension icon, then the three dots, then Settings, then Permissions. Source: permissions guide.
Good to know: Claude will always ask before high-risk steps like downloading a file or entering sensitive information, and it's hard-blocked from making purchases, entering card or ID data, and creating accounts. Those guardrails are on whether you remember them or not.
go further

3 bonus prompts to run next

  • 🧾 Stack and compare. "Find every currently working code for this store, then tell me which single code (or allowed combo) gives me the lowest final total including shipping. Show your math."
  • 🚚 Free-shipping hunt. "I don't need a percentage off, I need free shipping. Find and test any current free-shipping codes or thresholds for this store, and tell me the cheapest way to hit free shipping on my cart."
  • 📩 First-order unlock. "Check if this store gives a first-order or newsletter-signup discount. If it does, tell me exactly how to trigger it and what the code or discount would be, so I can decide whether to sign up before I check out."
the craft

How to get the most out of it

  • 🌱 If you're new: run it on one simple store first with "Ask before acting" on, and approve each step so you can watch what Claude is doing. You'll see it's just clicking and typing what you'd do yourself, minus the tab-hopping.
  • ⚡ If you're a power user: keep a saved note of the prompt and reuse it across stores. Ask Claude to always report the codes it tried and why each failed (expired, minimum spend, wrong region), so over time you learn which stores actually reward code-hunting and which never do.
what to watch

The honest bit

  • 🕵️ Codes have to actually exist. Claude can only test real, public codes. If a store has no live public code, no tool can conjure one, so some carts just won't get a discount.
  • ⏳ It's not always instant. Searching and testing several codes can take a few minutes on a slow store, not the movie-fast version you see in a sped-up reel.
  • 🛡️ Anthropic advises against financial workflows. Claude in Chrome is enhanced with safety classifiers but still carries some risk (prompt injection from sketchy pages is the main one), and Anthropic explicitly recommends against using it to manage financial accounts. Testing a promo code on a normal store is fine, but keep it to reputable stores and always do the pay step yourself. Source: Use Claude in Chrome safely.
