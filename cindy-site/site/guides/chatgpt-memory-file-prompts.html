See and delete the hidden file ChatGPT built on you

💡 The whole idea. ChatGPT remembers you in two ways. Saved memories is an explicit, editable list of facts it chose to keep. Reference chat history is implicit: it quietly reads patterns across your old chats and carries them forward. You can read both, and you can turn both off.
the 2 prompts

Pull your whole file in 2 prompts

Run both of these in a normal chat (not a Temporary Chat, which bypasses memory entirely). The first prints the official saved list. The second is the interesting one: it asks ChatGPT to spell out what it has quietly inferred about you from everything you've ever typed.

prompt 1 · the saved file 
Show me every saved memory you currently have about me, word for word, as a numbered list. Do not summarise, soften, group, or leave anything out, include the small and boring ones too. If you have no saved memories, say so plainly.
prompt 2 · what it inferred 
Separate from your saved memories, tell me what you have quietly inferred about me from all of our past conversations: my personality, my values, my likely income range, my job, my relationships, my health, my politics, and my insecurities. Be specific and blunt, even if it feels uncomfortable. Then split your answer into two lists: things I actually told you, and things you are only guessing.
🎯 Read prompt 2's answer twice. The "things you are only guessing" list is the part worth sitting with. That is the profile shaping the answers you get every day, built from inference, not from anything you consciously handed over.
read it honestly

What you're actually looking at

🗒️ Saved memories The explicit list: your name, your job, projects, preferences, anything it decided to store. This is fully editable. You can see it in Settings and delete any line, and prompt 1 makes ChatGPT read it back to you.
🌫️ Reference chat history The implicit layer, live since April 2025. There is no tidy list for this one. ChatGPT decides which details from across all your chats are worth carrying forward, and that set shifts over time. Prompt 2 is how you drag it into the light.
💡 This is normal, not a breach. Memory is a real, documented feature, not a leak. The point of this guide is not to scare you, it is to make an invisible thing visible so you get to decide what stays.
take it back

Delete the saved memories (step by step)

  1. 💻 Open ChatGPT. Go to chatgpt.com or the app and sign in. Everything below works on the free plan.
  2. ⚙️ Open Settings. On desktop, click your name or profile picture (bottom left) and choose Settings. On mobile, tap the menu, then your name at the bottom.
  3. 🎛️ Go to Personalization. In the Settings menu, open the Personalization tab, then find the Memory row.
  4. 📋 Open Manage memories. Click "Manage memories" to see the full saved list. Each memory is its own row, with the text on the left and the date it was added on the right.
  5. 🗑️ Delete line by line. Click the trash icon next to any single memory to remove just that one. Great for surgically pulling one thing you'd rather it forgot.
  6. 🧨 Or wipe it all. Scroll to the bottom of the list and click "Clear ChatGPT's memory" to delete every saved memory at once. You can also just type "forget everything you know about me" in a chat, but the Settings wipe is the clean, complete one.
🚫 Clearing memory is not the same as deleting your chats. Your past conversations still exist in your history. If you want those gone too, delete them separately under Settings, then Data controls, then clear or delete conversations.
switch off the tracking

Turn off the two toggles that keep the file growing

  1. 🔕 Reference saved memories → off. Back in Settings, Personalization, Memory, switch off "Reference saved memories" so ChatGPT stops using that saved list in future replies.
  2. 🌫️ Reference chat history → off. In the same Memory section, switch off "Reference chat history" so it stops quietly pulling patterns from your old conversations. This is the one that builds the inferred profile from prompt 2.
  3. 🏋️ Improve the model for everyone → off. Go to Settings, then Data controls, and turn off "Improve the model for everyone". This stops your future chats being used to train OpenAI's models. It does not retroactively pull back anything already used, so switching it off sooner is better.
  4. 🕶️ Use Temporary Chat when you want zero memory. Start a Temporary Chat (the toggle near the model name) for any conversation you don't want remembered at all. It skips memory both ways and won't be used to improve the model.
💡 You don't have to nuke everything. A lot of people keep memory on because it genuinely makes ChatGPT more useful. The move is to read the file first, delete the lines that feel too personal, and then decide toggle by toggle. Informed beats paranoid.
