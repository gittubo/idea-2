One bit of honesty on the word "skills." Only one thing on this list (number 3) is literally an Agent Skill. The rest are core Claude features. I'm calling them skills loosely because they're all things Claude can do that most people never turn on. A few of the heavier ones (bigger usage, some connectors, Claude Code) sit on paid plans, but most of this works on the free plan.
start here

Make Claude actually know you

These four are the difference between a stranger who forgets you every chat and an assistant that has your context loaded before you type a word. Set these up first.

1. Projects A workspace that holds your files, links, and instructions so Claude carries the same context across every chat inside it. One Project per real thing you work on, and you stop re-explaining yourself.
2. Memory Claude remembers your preferences and past work instead of starting cold each time. Tell it once how you like things, and it holds onto it.
3. Skills Drop-in instruction packs that make Claude do a task the same way every time. Anthropic open-sourced a pile of them, and you can build your own. This is the one that's literally called a skill.
4. MCP connectors Plug Claude into your real apps: Gmail, Notion, Drive, Calendar. Now it doesn't just talk about your work, it can read and act on it.
in the chat

What it can do inside a single chat

These live right in the conversation. No setup, they just quietly change what a "chat" even is.

5. Artifacts Ask for an app, a doc, a calculator, or a dashboard and Claude builds it live in a side panel you can use and share, not just describe.
6. Code execution It runs real code in a sandbox to get the answer instead of guessing. Great for math, data, and anything where "roughly" isn't good enough.
7. Web search Pulls live information from the internet instead of leaning on stale training data, and cites where it got it.
8. Subagents Little specialists, each with their own context, that work in parallel on parts of a big task. You get more done without one giant messy chat.
level up

Where it stops chatting and starts working

The last three are where Claude leaves the chat box and acts more like a teammate running in the background.

  1. ⏰ 9. Scheduled tasks. Claude runs a job on a timer without you asking, like a morning brief that lands before you're even up. Set it once, wake up to the output.
  2. 🌐 10. Claude in Chrome. The browser extension lets Claude work right where you already are, reading and helping with the page in front of you instead of you copy-pasting into a separate tab.
  3. 💻 11. Claude Code. The agent that builds and edits real projects for you, file by file, in your actual codebase or folder. This is the deep end, and it's where the real leverage is.

Set up a morning brief in two minutes

Scheduled tasks (number 9) are the fastest "oh, this is different" moment. Open Claude, hook up a connector or two, and give it this so it runs itself every morning.

☕ my daily morning brief 
Every weekday at 7am, send me a short morning brief. Pull today's events from my calendar, flag any emails from the last 24 hours that look like they actually need a reply, and give me the top 3 things I should focus on today based on what's due. Keep it under 150 words, plain and skimmable, no filler. If nothing urgent came in, just say so.

Set it as a scheduled task and Claude will run it on its own from then on. Swap the sources for whatever you've connected (Notion, Drive, a to-do list).

Do not try to switch on all eleven this week. Set up a Project and turn on Memory today, connect one app you live in, and add the rest as you hit a wall. The point isn't collecting features, it's Claude quietly knowing more about your work every time you open it.
