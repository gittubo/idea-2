💡 What makes something an agent. Not a chatbot that answers you: an agent perceives something (a page, an inbox, a customer message), decides what matters, and acts (alerts you, updates an app, replies). All five below do that loop. Number one does the simplest version of it, which is exactly why it's the best place to start.
agent one

A page watcher · Visualping

Free plan, about 5 minutes. Point it at any web page (a competitor's pricing, a job board, a council notice, a product listing) and it watches on a schedule, uses AI to judge whether a change actually matters, and summarises what changed. The fastest possible "I built an agent" moment.

How to start: install the Chrome extension, open the page you care about, select the region to watch, and set the frequency. That's the whole build.

visualping.io

agent two

An app-to-app agent · Zapier Agents

Free basic access, about 30 minutes. Start from a template, describe what you want in plain English, and the agent works across the apps you already use. This is the one that teaches you how agents think about tools, because you can see each action it takes.

Honest limits: the free tier gives you 400 agent activities a month with a maximum of 10 activities per run, and "AI by Zapier" steps are not included on free. Paid starts around $20/month if you outgrow it.

zapier.com/agents

agent three

Claude with connectors

Works on the free plan, about 15 minutes. The one with no builder interface at all. You connect a service (Google Calendar, Drive, Notion) and then just tell Claude what to handle in plain language. For most people this is the first agent that becomes part of daily life rather than a demo.

Honest limits: connectors work on every plan including Free, but Free is capped at one custom connector and five projects. Memory and custom skills are paid-plan features, so don't plan around those on free.

claude.com

agent four

A customer-answering agent · Tidio Lyro

50 free conversations, about an hour. It scrapes your own website into a knowledge base, then answers customer questions from it and hands off to a human when it's out of its depth. If you have any kind of business or side project with a site, this is the one that pays for itself first.

Honest limits: the free tier is 50 Lyro conversations with no card required, then roughly $0.50 per conversation. Treat it as a real trial, not a permanent free tool.

tidio.com/lyro

agent five

An agent that builds itself · MindStudio

Free tier, about an hour. You describe the agent you want in a sentence or two and their builder generates it for you, then you refine it. The closest thing to "tell the computer what you want and get an agent back", and a genuinely fun place to end the day.

Honest limits: the free tier exists but runs on credits, so heavy testing will eat them. Build one agent well rather than five sloppily.

mindstudio.ai

The ones that say no-code and aren't

🚫 Checked and cut. Chatbase: the free tier is a plain chatbot, and the AI Actions that would make it an agent sit behind a $120/month plan. n8n: brilliant tool, but even a template start means wiring credentials and API keys, which isn't zero-experience. Notion custom agents: genuinely no-code, but Business plan and up only. Relay.app: often recommended as the easy option, and it's shutting down in September 2026, so don't build on it. MARA: polished review-responder, no permanent free tier.
after your first one

How to make it actually useful

Pick a real annoyance Agents built for a genuine irritation get used. Agents built to be impressive get abandoned by Thursday.
Start read-only Let it watch and tell you before you let it act. Trust is earned in one direction only.
Keep a human gate Draft, don't send. Suggest, don't buy. That single rule makes agents safe to run on your real accounts.
Record it working A 30-second clip of your agent doing its job is the thing you show people. Nobody wants to read a config.
🌱 Honest expectation. These are real agents, but small ones. That's the right size for a first build: something that runs by itself, does one job, and teaches you the loop. The people building impressive agent systems started exactly here.
