step one · understand

AI Agents Explained · Tech With Tim

21 minutes, published July 2026. The correct mental model before you build anything: what an agent really is (a model using tools in a loop until the job is done), plus 4 ways to build one, from no-code to full code.

▶ Watch: AI Agents Explained (Tech With Tim)

💡 Watch for this. The "model using tools in a loop" definition is the single most useful idea in the whole space. Once you have it, his 4 tiers (no-code, low-code, agent harness, full code) show you exactly which way of building fits you.
step two · build

Build Your First AI Agent · n8n official

21 minutes, published February 2026, from n8n's own channel. You build a Q&A agent with its own knowledge base: an ingest flow that loads your documents, then an agent that answers from them. Use n8n's free 14-day trial, or self-host n8n free. It's a product tutorial, so it teaches n8n's way of doing agents rather than theory, which is exactly what you want on build day.

▶ Watch: n8n Quick Start, Build Your First AI Agent

📌 Do it, don't watch it. Open n8n in a second window and build along. 21 minutes of following along beats two hours of nodding.
step three · go deep

Claude Agent SDK Workshop · AI Engineer

1 hour 52 minutes, published January 2026. A full workshop taught by an engineer on Anthropic's Claude Code team, on the Claude Agent SDK, which is the same harness Claude Code itself runs on: tool definitions, the agent loop, subagents, and context management. This is the most in-depth free walkthrough of how Claude Code's agent loop works, and it assumes some comfort with a terminal, so it's deliberately last.

▶ Watch: Claude Agent SDK, Full Workshop (AI Engineer)

🌱 If it feels too technical: pause it, build the n8n agent again with a different tool connected, then come back. The workshop lands much better once you've built twice.
