The install everyone gets wrong. You do not install a skill by pasting a GitHub link into the chat and asking Claude to "install it." That is not a real mechanism. A skill is a folder with a SKILL.md inside, and there are two proper ways to add one: the npx skills add command in Claude Code, or uploading a zip on claude.ai. Exact steps are at the bottom, so nobody gets stuck.
first, the basics

What a Claude skill actually is

A skill is a reusable instruction file that Claude loads by itself the moment a task matches it. Instead of re-pasting the same giant prompt every time, you install the skill once and Claude just knows how to do that job your way. Think of it as teaching Claude a specialty and having it remember forever.

the 5

The 5 I'd install first, easiest first

Ordered from the one that gives you the most for the least effort, up to the one that compounds hardest.

  1. 📚 awesome-claude-skills. The library to shop from, not a single skill. This GitHub index (ComposioHQ/awesome-claude-skills, around 72k stars) sorts hundreds of ready-made skills into categories: writing, business and marketing, data and analysis, creative, design. Start here to see what already exists before you build anything.
  2. ⚡ superpowers. This one (obra/superpowers) teaches Claude Code to work like a senior developer: clarify the requirement, write a plan, then build with tests and review, instead of jumping straight to messy code. If you vibe-code apps or sites, the output quality jumps.
  3. 📊 Claude's own slides and docs skills. Turn a pile of notes into a real PowerPoint or Word doc right inside Claude, no Google needed. These are Anthropic's official pptx and docx skills, and they're already built into claude.ai, so you can often just say "make me a deck from these notes" and download the file.
  4. 📈 marketingskills. If you market anything, start here. This collection (coreyhaines31/marketingskills, around 44k stars) covers SEO, paid ads, ad creative, copywriting, CRO, and analytics as separate skills you can pull in one at a time.
  5. 🏗️ skill-creator. The most powerful one, because it makes the other four unnecessary to hunt for. Describe a workflow you repeat and Anthropic's official skill-creator writes you a custom skill for it. Install five, then build your own, that's when it really starts paying off.
copy these

How to actually install them

Two paths depending on where you use Claude. Pick your lane.

  1. 💻 In Claude Code (the terminal). For a repo skill, run npx skills add coreyhaines31/marketingskills (swap in any owner/repo). For the official plugins, use /plugin install skill-creator@claude-plugins-official and /plugin install superpowers@claude-plugins-official. That's it, no GitHub-link-in-the-chat needed.
  2. 🌐 On claude.ai (no terminal). Go to Customize, then Skills, hit Add and upload the skill as a zip with its SKILL.md at the top level, then toggle it on. It works on any plan, Free included. The slides and docs skills are already built in, so for those you just ask.
  3. 🔎 Browse before you install. Open awesome-claude-skills, find the one skill you actually need this week, then install just that one with the method above. Don't bulk-install things you won't use.
the compounding one

Build your own skill in one prompt

Once skill-creator is installed, this is the move that makes Claude yours. Point it at a task you do over and over.

🏗️ build me a custom skill 
Use skill-creator to build me a skill for [the exact task you repeat, e.g. turning my rough notes into a client-ready email]. Ask me any questions you need first, then write the SKILL.md so it captures how I like this done: my tone, my format, and the steps in order. When it's finished, tell me exactly how to install and trigger it.
If you only do two things this week: install skill-creator and grab one skill from the library that matches a task you're already doing. The downloaded ones get you started, but the custom ones you build for your own workflow are what make Claude feel like it was made for you.
