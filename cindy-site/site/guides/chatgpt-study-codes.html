Three ChatGPT study codes, plus your own

Set up the content before the picture

These three names are custom labels for prompts, not built-in ChatGPT commands. Paste the complete definition before invoking its nickname in the same chat. Save the full definition if you want to reuse it in a new conversation. A name on its own does not reliably specify the layout, source rules or learning goal.

  1. Choose one small learning objective, such as “name the eight planets in order and distinguish the Sun from a planet.” A whole semester is too much for one readable image.
  2. Attach or paste the relevant source extract, plus its title and URL or page number. Tell ChatGPT your current level. If you supply a link, ask it to confirm it can read the page; if it cannot, paste the section yourself.
  3. Ask for a short factual content plan before generating the image. Check names, definitions, relationships and any equations against the source.
  4. Paste a visual prompt below. Review its labels against the approved plan, then cover the page and practise retrieving the ideas.

You can request images in ChatGPT or select Images. Image generation is currently available on all tiers, with account-specific usage limits. You can revise a generated image in conversation. OpenAI’s current image instructions explain the available controls.

A small example you can use now

Our example is the solar system at an introductory level. Use NASA’s solar system overview to check the content. The Sun is a star. The eight planets, outward from the Sun, are Mercury, Venus, Earth, Mars, Jupiter, Saturn, Uranus and Neptune. Pluto is classified as a dwarf planet. These are enough facts for one first page.

A diagram should say “not to scale” unless its sizes and distances are deliberately scaled. A planet's place in the sequence does not mean it causes the next planet. This is the kind of small visual mistake that can turn neat notes into misleading notes.

A small example you can use now
Help me prepare accurate content for a visual study aid about the solar system. My learning goal is to name the eight planets in order and explain how the Sun and Pluto differ from those eight planets. My reference is https://science.nasa.gov/solar-system/. Confirm whether you can read it; if not, ask me to paste the relevant extract instead of pretending you checked it. Produce a concise content plan with the ordered planet names, one sentence distinguishing the Sun, and one sentence classifying Pluto. Keep source-backed facts separate from any suggested explanation. Flag uncertainties and do not generate an image yet. Wait for me to approve the plan.

For another subject, replace the topic, goal and source. A textbook chapter, your lecturer's notes or a primary technical document can work better than an open-ended internet summary. If the source is incomplete, keep the gap visible.

1. /generate handwritten image

Use this when you want a single overview you can revisit. Keep the page short enough that its handwriting remains readable on your phone. The handwritten appearance is a format choice, not a learning advantage on its own.

1. /generate handwritten image
For this conversation, /generate handwritten image means create a readable handwritten-style study page from the content plan I approved above. Use that approved plan as the factual boundary; do not add unsupported facts to fill space. Create one portrait page on warm cream paper with a clear title, simple labelled diagrams and no more than five short text sections. For the solar-system example, show all eight planets in the approved order, distinguish the Sun from the planets, place Pluto in a separate dwarf-planet note and label the diagram not to scale. Use dark readable handwriting, generous spacing and restrained orange accents. Copy names exactly from the approved plan. Generate the image now, then provide its exact text separately so I can check it and use it if image lettering is wrong.

Check every label, including small captions. If the page looks crowded, reduce the scope or split it into two pages. Smaller lettering rarely solves a learning problem.

2. /visualize learning

Choose this for relationships: a sequence, hierarchy, comparison or genuine cause-and-effect process. The arrows need to mean something. For the solar system, use ordering and classification rather than invented causal arrows.

2. /visualize learning
For this conversation, /visualize learning means turn my approved content plan into one clear labelled learning diagram. First choose the appropriate structure for the content: sequence, hierarchy, comparison or cause and effect. State what every arrow or connecting line means, and never turn an association or sequence into a causal claim. For the solar-system plan, use a sequence outward from the Sun with all eight planets in order, a separate note that the Sun is a star and a separate note that Pluto is a dwarf planet. Label sizes and distances not to scale. Use large text, simple shapes, a cream background and only two accent colours. Generate the diagram now and give me a plain-text version of its labels and relationships for checking.

A good test is to point to a line and explain it aloud. If you cannot say what it means, remove the line or replace it with a named relationship. For a more complex topic, ask for one diagram per relationship type.

3. /sticky-notes

Use this to separate ideas you need to compare or recall. Colours should identify categories, not decorate every sentence. Sticky notes are not automatically the best format for memory; the useful next step is trying to retrieve the information without seeing it.

3. /sticky-notes
For this conversation, /sticky-notes means turn my approved source-backed content into a small set of digital study notes, with one idea per note. Make one readable image containing six equal-size notes on a plain cream background. For the solar-system plan use these six ideas: the Sun's classification, the first two planets, the next two planets, the next two planets, the final two planets, and Pluto's classification. Retain the correct planet order within and between the numbered pair notes. Use at most three muted colours to distinguish classification from ordered names, and include a short legend. Keep wording concise and factual without inventing memory claims. Generate the notes now, then provide the note text and one answerable recall question per note separately in the chat.

For your own topic, change the six ideas and the number of notes if needed. Do not squeeze several definitions into one note to meet an arbitrary count. The point is to give each question a clear answer.

Turn the page into practice

Read the finished page once, hide it and explain the topic in your own words. Then use the prompt below. Answer before revealing the source. Mark what you missed and return to those gaps later, rather than rereading everything equally.

Turn the page into practice
Use only the approved content plan from this conversation to test my understanding. Ask one question at a time and wait for my answer before giving feedback or the next question. Start with an unaided recall question, then ask a comparison question and an explanation question appropriate to the source. After each answer, identify what is correct, quote or point to the relevant part of the approved source for any correction, and distinguish an omission from a factual error. If the source cannot settle something, say so instead of grading it confidently. Keep a short list of concepts I miss and revisit one after two other questions. Begin with the first question now; do not show its answer yet.

For our example, you should be able to name the eight planets in order and explain why the Sun and Pluto are not included in that list of eight. A colourful page you cannot explain is a cue to practise, not a failed design.

Make your own study code

Start with the learning job: comparing two concepts, following a process or applying a formula. Then choose a visual structure that fits. The builder below turns that job into a full reusable definition.

Make your own study code
Create a reusable custom study shortcut for helping me compare two concepts I often confuse. Call it /compare-two and make clear it is an instruction label for this conversation, not an installed ChatGPT command. Write a complete definition that asks for the two concepts, my learning level and a source extract or readable source link. It should check the source before making a comparison, build a two-column table with matching criteria, add one worked example and one non-example, and flag missing evidence rather than guessing. Include an optional image version only after I approve the text, plus a plain-text companion and three recall questions with answers kept separate. Return one copyable definition and a filled example invocation using two suitable concepts from the source I provide. If I have not provided a source, ask for it before inventing an example.

Save that definition and change the learning job as your needs change. You can use the same approach for a process map or a formula sheet, with units, assumptions and a checked worked example included in the definition.

Fix the common misses

If a diagram has wrong lettering, correct the text plan first and regenerate only that section. Keep a plain-text version so you can study without relying on generated typography. For important equations, verify symbols, units and each worked step in text before rendering anything.

If the explanation is vague, narrow the objective and provide a shorter source extract. If the model invents a citation, remove the unsupported point and ask it to identify the exact passage it used. A confident answer is not evidence that the source says it.

If ChatGPT produces a description instead of a picture, explicitly ask it to generate the image from the approved plan or use Images. When generation is unavailable, the checked text outline and one-question-at-a-time practice still let you continue studying.

Your first action

Start with the solar-system content-check prompt. Approve the facts, choose one of the three formats and answer the recall questions without looking. Then repeat that same source-to-practice workflow on a small topic you actually need to learn.
