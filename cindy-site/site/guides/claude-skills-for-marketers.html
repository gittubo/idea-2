the setup

How to add a skill (about 30 seconds)

You do not need to code. Two easy paths:

  1. 🌐 On claude.ai go to Customize, then Skills, click Add, and upload the skill (as a zip). It works on any plan, Free included.
  2. 💻 In Claude Code unzip the skill folder into ~/.claude/skills/ (for every project) or a project's .claude/skills/ folder. Or just point Claude at the GitHub repo and ask it to install the skill for you.
The download button gives you the same zip you upload on claude.ai, ready to go. Each zip also keeps the skill's original licence and a SOURCE file crediting the author. Then either ask Claude to use it, or let it load on its own when your request matches. One honest note: a couple of skills in these repos call external tools or APIs for live data, so read each skill's README before you lean on it.
