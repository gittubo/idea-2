Before you press play

📌 Install Claude Code first so you can follow along, it's the fastest way to actually retain any of this. You'll need Node.js and a Claude account (both free to set up).
📌 Watch #1 and #2 back to back (about an hour total). That alone gets you past the I don't know where to start wall.
📌 Then build one tiny real thing before moving on. Momentum beats more watching.
start in 15 min

The quick starter (begin in 15 minutes)

Before the videos, the fastest way to actually start:

  1. 💻 Install Claude Code: run npm install -g @anthropic-ai/claude-code (you'll need Node.js), or use it in the browser at claude.ai/code. Sign in with a Claude Pro or Max plan.
  2. 📂 Open your terminal, go into any folder (or make a new one), and type claude to begin.
  3. 🛠️ Give it one small real job, like "build me a simple habit tracker as a single HTML file" or "organize the files in this folder." That first build is the moment it clicks.
  4. 📝 Add a CLAUDE.md file to your project with a few notes about you and what you're building, so it remembers your context every time.
  5. 🎙️ Try /voice to talk to it instead of typing.
That's genuinely it, you're now using Claude Code. The videos below take you the rest of the way.
