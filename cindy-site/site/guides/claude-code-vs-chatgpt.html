the reframe

The one-line difference

Chatbots like ChatGPT, Gemini, and Claude.ai work at the conversation level: you ask, they answer, maybe with a code snippet you copy, paste, and hope works.

Claude Code works at the project level: it lives in your terminal, reads your actual files, understands your whole project, writes the code, runs it, hits an error, fixes it, and runs again, all on its own. You describe the outcome you want and direct it. You are the conductor of the orchestra, not the person typing every note.

That loop (read, write, run, fix, repeat) is the exact loop a developer does by hand. Claude Code just does it for you while you steer.

before you start

What you need before you start

💳 A paid Claude plan or API access. Claude Code needs a Claude Pro, Max, Team, or Enterprise subscription, or a Claude Console (API) account with credits. The free Claude.ai plan does not include Claude Code. Source: official Claude Code quickstart.
💻 A terminal. On Mac it is the Terminal app. On Windows, PowerShell (or the newer native installer). If the word terminal makes you nervous, that is normal, and you will only need to paste one line.
the setup

Install Claude Code in about 5 minutes

The recommended way in 2026 is the native installer, which also auto-updates itself in the background. Paste the line for your system into your terminal and press enter.

Mac, Linux, or WSL:

🍎 mac, linux, or WSL installer 
curl -fsSL https://claude.ai/install.sh | bash

Windows PowerShell:

🪟 windows powershell installer 
irm https://claude.ai/install.ps1 | iex

Once it finishes, start Claude Code by typing:

▶️ start a session 
claude

On first run it will prompt you to log in. Follow the browser prompt to connect your Claude account, and you are in. To switch accounts later, type /login inside the session.

Prefer npm? The legacy path still works if you already have Node installed:

📦 the npm route 
npm install -g @anthropic-ai/claude-code@latest

Anthropic recommends the native installer over npm now, but npm is fine if that is your comfort zone. Source: Claude Code quickstart.

your first run

Your first 10 minutes with Claude Code

  1. Point it at a real folder. In your terminal, move into any project folder (even an empty one) and run claude. It reads the files there automatically, so you never paste code in manually.
  2. Let it explore first. Before asking for changes, ask it to understand the project:
    🔍 orient it 
    what does this project do, and what technologies does it use?
  3. Ask for a real change. Describe the outcome in plain English. Claude Code finds the right file, shows you the proposed edit, and asks permission before saving:
    ✏️ make a change 
    add a simple contact form to the homepage, then tell me what you changed
  4. Let it run and fix itself. For anything with tests or a build step, tell it to run and self-correct. This is the part chatbots cannot do:
    🔁 the self-correcting loop 
    build the project, and if anything breaks, fix the errors and run it again until it passes
  5. Use it for Git too. It makes version control conversational, no memorizing commands:
    🌿 conversational git 
    commit my changes with a clear message, then show me the last 5 commits
go further

3 bonus prompts to run next

  • ⚙️ Turn it into a repeatable teammate. Ask it to write a CLAUDE.md so it remembers how your project works next time:
    1 · the project memory 
    look at this project and write a CLAUDE.md that captures the folder structure, the commands to run and test it, and the conventions you should follow, so future sessions start with full context
  • 🧪 Ship with a safety net. Get it to add tests around new code so future changes do not silently break things:
    2 · the safety net 
    write unit tests for the code you just added, run them, and fix anything that fails
  • 🧭 Break a big idea into steps. Claude Code does best when a large task is spelled out in order:
    3 · plan before build 
    here is what I want to build: [describe your idea]. First write a step-by-step plan, wait for me to approve it, then build it one step at a time
the craft

How to get the most out of it

🌱 If you are brand new: talk to it like a helpful colleague, not a search box. Say what you are trying to achieve and why, and let it explore your files before asking for changes. Being specific ("fix the login bug where users see a blank screen after wrong credentials") beats vague ("fix the bug") every single time.
⚡ If you already build: lean into the agentic loop. Give it a plan, let it run tests and self-correct in one pass, and use a CLAUDE.md plus custom skills so every session starts with your project's context loaded. Press Shift+Tab to cycle permission modes when you want it to move faster. Full playbook in best practices.
when not to

When a chatbot is still the right tool

Claude Code is built for doing work inside a project. If you just want to brainstorm, learn a concept, or get a quick explanation with no files involved, a normal chatbot (ChatGPT or Claude.ai) is faster and simpler. Reach for Claude Code when you actually want something built, changed, or shipped.
