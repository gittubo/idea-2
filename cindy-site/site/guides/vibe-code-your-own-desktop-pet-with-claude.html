Vibe-code your own desktop pet with Claude

Hey, it's Cindy 🌱 Build a little pixel pet for your desktop that follows your cursor and cheers when your Claude agent finishes a task.

the outcome

What you're making

A small, always-on-top desktop character (a cat, a crab, anything you like) that idles with a gentle animation, follows your cursor, reacts when you type, naps when you go quiet, and plays a happy celebration when triggered. It is pure fun, and genuinely one of the best first vibe-code projects because you see it react instantly.

step 1

Describe your pet to Claude Code

Open Claude Code in a new folder and paste this, filling in the brackets with the pet you want.

🐱 the build prompt 
Build me a small desktop pet as a lightweight always-on-top app (use a simple
Electron or Tauri shell, or a menu-bar overlay, whatever is simplest to run on my
Mac). The pet is [a chubby pixel cat] with a [playful, sleepy] personality, drawn in
[simple 2D pixel-art] style. Behaviours: it idles with a gentle animation, it follows
my cursor around the screen, it plays a typing animation while I type and looks
startled if I type very fast, it naps if I am idle for a while, and it plays a happy
celebration animation when triggered. Expose a simple local trigger (a file it
watches, or a local http ping) so I can make it celebrate when one of my Claude Code
agents finishes a task. Keep it a single small project I can run with one command,
make the window transparent and click-through except on the pet, and tell me exactly
how to start it. Then run it and show me a preview.
step 2, the fun part

Make it cheer for your agents

Ask Claude to add a tiny hook so that when a Claude Code run finishes, it pings your pet and it celebrates (a Stop hook that touches the watched file or hits the local ping). Now your pet cheers every single time your agent ships.

step 3

Keep tweaking

This is the joy of vibe-coding, you just ask for more: a purr when you click it, a drag-to-stretch mochi effect, an overheat animation with steam if you type too fast. Say what you want and Claude adds it.

🌱 Inspired by Comnyang, shared by simon_dsgn via Reddit. Build your own version, do not copy theirs. If you'd rather a code-drawn mascot, the same idea works for a little crab, a duck, anything.
