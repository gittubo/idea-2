the five from the reel

Over 329,000 stars between them

These five add real capability rather than prompts. All free, all open source, all checked on 2 October 2026.

  1. 1 · Open Design · 99k stars A collaborative design agent workspace you can self-host, so Claude works inside a real design surface instead of describing one. nexu-io/open-design
  2. 2 · AI Agents for Beginners · 76k stars Microsoft's free 21-lesson course on building agents. The best starting point if agents still feel vague. microsoft/ai-agents-for-beginners
  3. 3 · Career Ops · 73k stars Scores every job 1 to 5 against your actual CV before you waste an evening applying. career-ops-hq/career-ops
  4. 4 · Obsidian Skills · 49k stars Built by Steph Ango, Obsidian's CEO. Teaches your agent to drive Obsidian from the command line. kepano/obsidian-skills
  5. 5 · Vercel Agent Skills · 31k stars Vercel's official set. Its design-audit skill alone checks against 100+ UI rules. vercel-labs/agent-skills
⚠️ One wording thing, since you will see it repeated wrong. The "100+ checks" belongs to one skill inside Vercel's set, the design audit. It is not the total across the repo.

Which one to install first

Install order depends on what you are actually trying to do this week.

  1. 1 · Job hunting right now Career Ops, and nothing else until it has scored a dozen roles for you. career-ops-hq/career-ops
  2. 2 · Still fuzzy on what an agent is The Microsoft course, properly, with the exercises. It is 21 lessons and it is free. the course
  3. 3 · Shipping something that people will look at Vercel's design audit, because it catches the specific things that make a page read as AI-made. vercel-labs/agent-skills
  4. 4 · Living in Obsidian already Obsidian Skills. If you do not use Obsidian, skip it entirely, it does nothing for you. kepano/obsidian-skills
🌱 Four of these five are only useful if you already have the matching problem. Installing all of them because the star count is high is how your setup gets slow and confusing.
the honest bit

Read the last commit date
