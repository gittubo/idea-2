optional one-time upgrade

Tell compaction what it must never lose

If you use Claude Code for long projects, add this short rule to your project-level CLAUDE.md. It gives compaction an explicit preservation list. This is optional, not another setup project.

add once to CLAUDE.md 
When compacting, always preserve:
- the current goal and definition of done
- decisions already made and why
- every modified file
- unresolved errors or blockers
- commands and tests already run, with their results
- the exact next action

Keep CLAUDE.md lean

  • Keep only broad, non-obvious instructions that should apply in every session.
  • Move occasional knowledge and repeatable workflows into Skills so Claude loads them only when relevant.
  • For each line, ask: would removing this cause Claude to make a mistake? If not, cut it.
  • For a checked-in CLAUDE.md, run /doctor and review the cuts Claude proposes.

10 more Claude Code commands

These are the ones I actually use. All built in, nothing to install, and you type them straight into Claude Code.

  1. 🧭 /init Sets up a CLAUDE.md for the project you're in, which is the file Claude reads every session. Run it once in any project you'll come back to.
  2. 🧠 /memory Opens your CLAUDE.md files to edit, and lets you turn auto memory on or off and see what it has saved.
  3. 📝 /plan Drops you into plan mode, so Claude works out the approach and shows you before it touches anything. Use it for anything you can't easily undo.
  4. 🔄 /model Switches which model you're using and saves it as your default for new sessions.
  5. 📊 /autocompact Sets how full the context window gets before Claude compacts automatically. Useful if it keeps compacting in the middle of your work.
  6. 👀 /diff Shows every change in your working files, including everything Claude edited. Read this before you commit anything.
  7. 📋 /copy Copies Claude's last answer to your clipboard, so you don't have to select it by hand.
  8. 💾 /export Saves the whole conversation as plain text. Good for keeping a build you'll want to repeat later.
  9. 🌿 /branch Branches the conversation from this point, so you can try a different direction without losing what you have.
  10. 🩺 /doctor Runs a checkup on your setup, tells you what's broken, and can fix a lot of it for you.
💡 Two more if you like working in the background. /fork copies the conversation into a background session and leaves you working here, and /background detaches the session you're in so your terminal is free again.
🌱 Can't remember any of them? Type /help to see the full list inside Claude Code, and the official reference lives at code.claude.com/docs/en/commands.
