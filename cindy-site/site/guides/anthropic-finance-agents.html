The bit that trips people up. The names Anthropic uses in the announcement are not the names you install. "Pitch builder" installs as pitch-agent, "Meeting preparer" as meeting-prep-agent, and "General ledger reconciler" as gl-reconciler. If you go looking for the announcement names in the marketplace you will not find three of them. The table below maps both.

What actually shipped

Ten ready-to-run agent templates for financial services. Each ships as a plugin for Claude Cowork and Claude Code, and as a cookbook for Claude Managed Agents if you want to run them programmatically. They are available on all paid plans, so this is not an enterprise-only release.

They are not chatbots with a finance prompt. Each one is a small team: a reader, a builder or critic, and a writer that produces the deliverable. The earnings-reviewer, for example, runs a transcript-reader, then a model-updater, then a note-writer, and hands you back a research note plus an updated model.

install

Two ways in

In Claude Code, it is two commands. Add the marketplace once, then install whichever agents you actually want.

⌨️ Claude Code install 
claude plugin marketplace add anthropics/financial-services

claude plugin install pitch-agent@claude-for-financial-services
claude plugin install earnings-reviewer@claude-for-financial-services
claude plugin install model-builder@claude-for-financial-services

In Claude Cowork, it is a menu. Open Customize in the left sidebar, then Browse plugins, choose Personal, hit the + button and pick Add marketplace from GitHub. Point it at anthropics/financial-services.

💡 If the menu names differ slightly. Anthropic's docs describe the path as Customize then Browse plugins; the repo README describes it as Settings then Plugins then Add plugin. The UI has moved once already, so follow the shape of it rather than the exact labels: you are adding a GitHub marketplace, then installing from it.

The honest bit

This is not new this week
Anthropic announced these on 5 May 2026. They are excellent and most people still have not seen them, but if someone tells you this is a brand-new launch, it is four months old.
Paid plan, and Cowork is desktop
All paid plans, so not enterprise-only. But Cowork lives in the Claude desktop app, so the "any device" version of this is Claude Code, the CLI.
The 20 vs 10 thing
The marketplace holds 20 plugins, not 10. Ten are these agents. The rest are vertical toolkits (investment banking, equity research, private equity, wealth management, fund admin) plus partner plugins.
Connectors cost extra
The data connectors and the Moody's app are only for joint customers, and the repo notes MCP access may need a subscription or API key from that provider. The ten agents themselves do not.
