Find the right Claude skill instead of installing blind

Hey, it's Cindy 🌱 Find Skills is a skill whose only job is searching all the others for you, then handing you the best match.

One thing to know first. Find Skills is built for Claude Code (the terminal version of Claude) and it runs through npx, so you need Node.js installed. It is free and open source, published by Vercel Labs. If you only use Claude in the browser right now, save this for when you graduate to Claude Code, that is where skills really pay off.
the setup

Install it once

  1. 📦 Check you have Node. Find Skills runs through npx, which ships with Node.js. Open your terminal and run node -v. If you see a version number, you're set. If not, install Node from nodejs.org first, then come back.
  2. ⌨️ Run the one install command. In your terminal, run the command below. It adds the find-skills skill straight into Claude Code's skills folder. One line, done, no config.
  3. 🔎 Then just ask, in plain English. Next time you're in Claude Code and unsure what to reach for, describe your task and let Find Skills search the whole ecosystem and recommend the best matches. No special command to memorise.
npx skills add vercel-labs/skills --skill find-skills
Want it aimed at Claude Code specifically? Add the agent flag: npx skills add vercel-labs/skills --skill find-skills --agent claude-code. Same install, just explicit about the target.
use it

How to actually search for a skill

You don't invoke Find Skills with a magic word. You describe what you're trying to do and it finds the match, ranked by how many people use each skill and how trusted the source is (official and Vercel Labs skills float to the top). Ask it like this:

🔎 find a skill by describing the job 
I'm trying to [describe your task, e.g. turn a folder of PDFs into clean markdown].

Is there an existing skill that does this well? Search what's available, show me the top few matches with what each one does, how many installs it has, and who published it, then recommend which to install and why.

Prefer a quick one-liner straight from the terminal? Run a direct search with the query built in:

npx skills find "convert pdfs to markdown"
why it's worth it

Why this beats installing blind

Ranked by trust Results are sorted by install count and source reputation, so official and widely-used skills rise to the top, not random half-finished ones.
The right skill, not just any The problem was never finding a skill, it was finding one that fits your exact task. That is the whole job it does.
Free and open Published by Vercel Labs, open source, no account and no cost to use it.
