the three from the reel

The three that genuinely work, with no code

These use Claude's own Connectors, Skills and Scheduled tasks. No code, no automation platform. Each one takes about ten minutes once the connector is on.

  1. 1 · Meeting prep agent Reads tomorrow's calendar and writes you a brief on everyone you are meeting. Uses the Google Calendar connector, which is read-only, which is all this needs. the Calendar connector
  2. 2 · Competitor watch agent A Monday morning report on what your competitors changed. This is where Scheduled tasks earn their place. how scheduled tasks work
  3. 3 · Lead finder agent Twenty prospects with a personal first line for each, built as a Skill so it runs the same way every time. Customize, then Skills
⚠️ The two everyone gets wrong, and why nobody can actually deliver them. Claude's Gmail connector is read-only. Anthropic's own documentation says it "can't create, send, or modify messages". So an inbox agent can read and flag, but it cannot draft replies into your drafts, and a launch-email agent cannot leave a sequence sitting in Gmail for you. Anyone showing you that is either using a different tool or not showing you the whole thing.
do this once

The exact path, named the way Claude names it

Three menus, and most people get stuck because they skip the second one.

  1. 1 · Connectors Go to Customize, then Connectors. Find the app, select Connect, sign in. Customize, then Connectors
  2. 2 · Turn it on inside the chat This is the step people miss. In a conversation, select + at the lower left of the message box, choose Connectors, and switch the one you want on. the connector directory
  3. 3 · Skills, for anything you want repeated identically Customize, then Skills, then Create skill. Write the instructions once and it behaves the same way every time. Customize, then Skills
  4. 4 · Scheduled, for anything that should run without you In Claude Cowork, open Scheduled in the sidebar and choose New task. Hourly, daily, weekly, weekdays or manual. scheduling a task
🌱 Build one and let it run for a week before building the next. An agent you do not read the output of is just a notification.
what it costs

The part the word free hides

  1. 1 · Connectors need a paid plan The Gmail and Calendar connectors are on Pro, Max, Team and Enterprise. "No code" is true. "Free" is not. which plans get connectors
  2. 2 · Scheduled tasks are paid too They live in Claude Cowork and are not on the free plan, so the Monday report needs a subscription to exist. scheduled tasks
the honest bit

Read-only is a feature, not a bug

  1. 1 · Why Anthropic did it this way An agent that can send email on your behalf is one bad instruction away from an embarrassing problem. Read-only means the worst case is a wrong summary. the documented limits
  2. 2 · If you genuinely need drafting That needs a different tool with write access, and it is worth being deliberate about giving anything that permission to your inbox. the full directory
