Two honest things before you start. First, the "fit" or "interview chance" number Claude gives each job is an AI estimate from reading your resume against the listing, not a real prediction from any hiring system, so treat it as a smart sort order, not a guarantee. Second, salary only shows up when the listing itself published one, so you'll get pay where it exists, not on every role.
the tool

What's doing the work here

Claude on its own can't see live job boards. Apify is a library of ready-made scrapers (called Actors) that pull live listings from sites like Indeed and LinkedIn. You connect Apify to Claude once, and from then on Claude can call a job scraper, read the results against your resume, and rank them for you, all in one chat.

set it up

Connect Apify to Claude, free

  1. 🆓 Make a free Apify account. Sign up at apify.com. The free plan gives you $5 of usage every month with no credit card, which is plenty for this (the Indeed and LinkedIn scrapers cost a few dollars per thousand listings, and you only need twenty).
  2. 🔑 Grab your API token. In the Apify Console, go to Settings, then API and Integrations, and copy your personal API token. This is the key that lets Claude talk to Apify.
  3. 🔌 Add the connector in Claude. In Claude, open Settings, then Connectors, and add Apify. Search the connector directory for it, or add it as a custom connector using the URL https://mcp.apify.com. Sign in to Apify when it asks (or paste your API token), and switch it on.
Plan note, so it doesn't catch you out. Adding a custom remote connector on claude.ai needs a paid Claude plan. If you're on the free plan, use the free Claude Desktop app or Claude Code instead, where the Apify connection works without a paid tier. The Apify side stays free either way.
pick a scraper

Two job scrapers that fit the free tier

Tell Claude which board to pull from. These two are cheap enough to run inside your free $5 monthly credit.

Indeed scraper Actor misceres/indeed-scraper. Pulls live Indeed listings from about $3 per 1,000 jobs. Great default for most roles and countries.
LinkedIn Jobs scraper Actor curious_coder/linkedin-jobs-scraper. Pulls LinkedIn job posts from about $1 per 1,000 results. Best for corporate and tech roles.

Twenty jobs is a tiny fraction of a thousand, so a full run here costs you cents, well inside the free credit.

run it

Upload your resume and run this

Attach your resume to the chat (PDF or doc), then paste this. Claude will call the scraper, pull live roles, and rank them against you.

💼 find me 20 matched jobs 
Attached is my resume. Using the Apify connector, run the Indeed scraper (misceres/indeed-scraper) to pull live job listings for [job title / field] in [location, or "remote"].

Then read those listings against my resume and give me the 20 best matches as a table with: job title, company, location, salary (only where the listing states one), and a short reason it fits me. Add a rough fit score out of 10 based on my experience versus what the role asks for, and be clear that score is your estimate, not a real prediction. Sort the table best fit first. If fewer than 20 are a genuine match, give me only the real ones rather than padding the list.

Want LinkedIn instead? Swap the actor name for curious_coder/linkedin-jobs-scraper. Want to widen the net? Ask Claude to run both and merge the results.

the honest read

What you actually get

A real shortlist Twenty live roles ranked to your actual experience, in seconds, instead of an afternoon of scrolling and second-guessing.
Not a magic wand The fit score is Claude's estimate and salary only shows where the listing has it. Use the ranking to decide where to apply first, then still read each role yourself.
Once it works, save the prompt and rerun it weekly with fresh listings. You can also ask Claude to tailor your resume or write the cover letter for the top three, so the same setup takes you from finding the job to applying for it.
