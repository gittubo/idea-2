the five from the reel

Over 686,000 stars between them

Each of these fixes a specific annoyance in Claude Code. The names are not self-explanatory, so here is what each one is really for.

  1. 1 · Superpowers · 294k stars The agentic skills framework. Makes Claude plan, test and review its own work instead of charging at the first idea. obra/superpowers
  2. 2 · Anthropic's own skills · 179k stars 19 official skills: Word, Excel, PowerPoint, PDF handling and an MCP builder. The ones Anthropic maintains themselves. anthropics/skills
  3. 3 · Claude-mem · 95k stars Fixes the thing that annoys everyone: it remembers your last session instead of starting cold. thedotmack/claude-mem
  4. 4 · Context7 · 62k stars Pipes a library's current docs straight in, so Claude stops inventing functions that never existed. upstash/context7
  5. 5 · Awesome Claude Code · 54k stars The hand-picked index of everything else. Where to go when you want to browse rather than be handed a list. awesome-claude-code
match it to your annoyance

Which one fixes which problem

Pick by the thing that is irritating you, not by the star count.

"It forgets everything" Claude-mem. Persistent context between sessions. claude-mem
"It invents functions" Context7. Real documentation, piped in live. context7
"It charges in without thinking" Superpowers. Plan, build, review as separate steps. superpowers
"I need it to handle documents" Anthropic's own skills. PDF, Word, Excel, PowerPoint. anthropics/skills
"What else is out there" Awesome Claude Code, the curated index. the index
"I want it to build video" hyperframes, 55k stars. Write HTML, render a video. heygen-com/hyperframes
the honest bit

Two at a time, maximum

  1. 1 · Adding five at once makes it worse Skills change how Claude behaves. Install five together and when something goes weird you have no idea which one did it. start with one
  2. 2 · Memory tools see everything you work on Claude-mem stores session context on your machine. Fine for your own projects, worth a thought before you point it at client work. read what it stores
