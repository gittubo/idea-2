💡 What this does and does not do, stated plainly. Claude reads your live page, writes your style guide, and builds finished layouts as HTML (text, colour, type, shapes, icons, gradients). It does not shoot photography or generate photo-real images inside this build, and nothing below pretends it does. Layout-led posts (quotes, stats, tips, carousel covers, announcements) come out looking genuinely designed. Anything that needs a real photo of a real product still needs a photo, so leave a slot for one.
the shape of it

What one link actually gets you

1. A brand DNA file Voice, hex codes, type scale, spacing habits, imagery rules and banned words, written down once instead of re-explained in every chat.
2. Campaign ideas that fit Concepts generated against your DNA file, so they sound like your brand instead of like a generic content calendar.
3. Editable HTML creatives Each post built as a single HTML file at real post dimensions, with your brand values sitting at the top as variables.
4. A re-render loop Change one hex code or one headline, ask for the set again, and every creative updates together instead of one at a time.

The part that makes this feel like a design team rather than a prompt is the file in the middle. Once your brand exists as text Claude can read, every later request starts from your rules instead of from its defaults, and the output stops drifting between chats.

before you start

Setup, and the one thing that trips people

  1. 🆓 A Claude account, any plan. Nothing here needs a paid tier. Artifacts, the window where your HTML creative renders, are supported on "Free, Pro, Max, Team, and Enterprise plans" (Anthropic on artifacts). Plan limits: claude.com/pricing.
  2. 🔎 Web search on, so Claude can read your page. Click the slider icon in the chat input, find Web search, switch it on. With it on, Claude "can retrieve content directly from web pages when provided with specific URLs" (enable and use web search).
  3. 📋 The fallback when fetching fails. Some sites block automated readers, and some pages render their copy in a way Claude cannot reach. Open the page, select all, copy, and paste the raw text into the chat instead of the link. Every prompt below works the same way on pasted text.
  4. 📁 A project, so the DNA is reusable. Make a project called "Brand DNA" and add the file from step one to its knowledge. Every future design chat then starts inside your brand. All accounts can create projects, with free accounts capped at five (projects guide).
🌱 Pick the right page. Not the homepage. Use the page that carries the most brand: your about page, your sales page, or your best product page. A homepage is often a menu, and a menu gives Claude very little voice to read.
copy this first

Prompt 1: the brand DNA prompt

This is the one from the reel, in full. Run it on its own and read the output properly, because everything downstream inherits whatever it gets wrong.

🧬 extract my brand DNA 
Read this page and write me a brand DNA file I can hand to a designer: [paste your URL].

Structure it under these headings, in this order. Brand in one line: what this is and who it is for. Voice: five specific adjectives, each with a real quoted line from the page as evidence, plus a short "we say this, not that" list of words the brand uses and words it avoids. Colour: the actual hex codes you can see in use, labelled by role (background, text, primary accent, secondary accent, borders), and say which one carries the calls to action. Type: the heading font, the body font, and roughly how big headings are compared with body text. Layout habits: how much white space the page leaves, whether corners are rounded or square, whether it uses shadows, borders, or neither, and how wide the text column runs. Imagery: what the photos and graphics have in common, including lighting, colour temperature, whether people appear, and what would look wrong here. Proof: the strongest specific claims, numbers, credentials or testimonials actually on the page, quoted exactly. Audience: who is clearly being sold to and who is not.

Rules while you do it. Quote the page rather than paraphrasing whenever you are describing voice, and mark anything you are inferring rather than reading directly with "inferred", because I am going to build a whole visual system on this. If the page is thin on a section, write "not enough on the page" instead of inventing something plausible. Finish by writing the whole thing again as one clean markdown file called brand-dna.md, with no commentary around it, so I can save it as is. Do not use em dashes.
🧠 Argue with this output before you go further. Two things are worth fixing by hand every time. Hex codes read off a rendered page can be a shade out, so open your site, use your browser's colour picker or your own brand file, and correct them. And if the voice adjectives feel like someone else's brand, say so in one message and have it redo that section. Thirty seconds here saves you a whole set of off-brand creatives.
make it permanent

Save the DNA where every chat can see it

  1. 💾 Save the markdown. Copy the brand-dna.md block into a plain text file on your computer and name it brand-dna.md. This is now the source of truth for your brand, and it is yours, not locked inside a chat.
  2. 📂 Add it to your project. Open your "Brand DNA" project, add the file to the project knowledge, and every chat inside that project reads it automatically without you pasting anything.
  3. 📝 Add the human bits Claude cannot see. Open the file and add three things a website never states: who you are actually for in your own words, the two or three phrases you personally overuse, and anything that is off limits (a competitor you do not name, a claim you cannot make, a colour you have retired).
  4. 🔁 Date it and revisit it. Put the month at the top. When you rebrand, rerun prompt one against the new page and replace the file rather than patching it, so old rules do not linger.
prompt 2

Campaign ideas that actually match

Generic content ideas are the reason most brand tools feel useless. This prompt forces every concept back through the DNA file, and asks for the visual idea alongside the copy so the two are designed together.

💡 on-brand campaign concepts 
Using the brand DNA file in this project, give me eight social post concepts for the next month. Do not give me content pillars or a strategy essay, give me eight specific posts I could build this week.

For each one write: the concept in one line, the exact headline as it would appear on the creative in under nine words, one supporting line under twenty words, the visual idea described concretely (what is on the canvas, which brand colour dominates, whether it is one big number, a quote, a comparison or a list), and the caption angle in a sentence. Vary the formats deliberately so this does not turn into eight versions of the same card: include at least one single-number stat, one myth versus reality, one short list, one quote from the page, and one before and after.

Every concept has to be traceable to the DNA file, so after each one add a short line saying which part of the brand it is drawing on, for example the voice adjective, the proof point or the audience it targets. If a concept needs a claim that is not in the file, say so rather than inventing the claim. Rank the eight from strongest to weakest at the end and tell me honestly which two you would cut.
💡 Ask for eight and cut to five. Ranking is the useful part, because a model that has to defend an order gives you sharper reasoning than one that hands you a tidy list of ten equal-looking ideas.
prompt 3

Build each creative as editable HTML

This is the step that replaces the Canva afternoon. Claude writes each post as a single HTML file, which renders live in an artifact, and every brand value sits at the top as a variable rather than being scattered through the layout. That is what makes the whole set editable later.

🎨 build the creative 
Build concept [number] as a single self-contained HTML file I can screenshot as an Instagram post, using only the colours, fonts and layout habits in the brand DNA file.

Technical requirements. The canvas is exactly 1080 by 1350 pixels, set on a wrapper div with fixed width and height and overflow hidden, so nothing spills or reflows. Put every brand value in one :root block of CSS variables at the very top, named by role: background, text, muted text, primary accent, secondary accent, border radius, and the two font families. Nothing lower down may hardcode a colour or a font, everything references a variable, because I am going to change one line and re-render the whole set. Load fonts from Google Fonts if the brand fonts are available there, and if they are not, pick the closest match, name your substitute in a comment at the top, and tell me in the chat what you substituted and why.

Design requirements. One idea per canvas and one clear focal point. Type at post scale, so the headline is large enough to read on a phone at thumbnail size, roughly 64 to 96 pixels, and never smaller than 32 for supporting text. Leave generous margins, at least 80 pixels on every side. Use the accent colour on one element only, so it stays an accent. No stock icons, no clip art, no gradients unless the DNA file says the brand uses them, no lorem ipsum: use the real headline and supporting line from the concept.

Then render it as an artifact so I can see it, and underneath tell me in three bullets which brand rules you applied and anything you had to guess.
  1. 👀 Look at the artifact first. Claude renders single page HTML directly in the artifact window, so you see the finished post beside the chat. Judge it at a distance, the way it will be seen in a feed.
  2. ✂️ Fix it in words, not in code. Say what is wrong in plain language: "headline is too small", "too much going on in the bottom third", "the accent colour is doing too much work". Claude edits the file and re-renders. You are art directing, not coding.
  3. 📸 Export it. Screenshot the artifact at full size, or download the HTML file (the artifact window has a download option), open it in your browser, and screenshot there. Zoom the browser to 200 percent before screenshotting so the exported image is sharp rather than soft at post size.
  4. 🗂️ Keep the file. Save each HTML file in a folder next to your brand-dna.md. That folder is your template library, and next month you edit instead of starting over.
prompt 4

The bit most people miss: everything stays editable

A Canva design has to be updated one file at a time. A set built on variables updates together, which is the whole reason to build creatives as code rather than in a canvas tool.

🔁 re-skin the whole set 
Here are the creatives we have built so far. I want to change the system, not the individual posts.

Change [the primary accent to #XXXXXX / the heading font to X / the border radius to X], then regenerate every creative with that change applied, keeping every headline, every piece of supporting copy and every layout exactly as it is. Only the variables in the :root block should differ between the old version and the new one, so if you find yourself rewriting layout to make the change work, stop and tell me which creative is fighting the change instead of quietly redesigning it.

After the set is regenerated, show me each one and flag any where the new value breaks something real: contrast that is now too low to read, a headline that no longer fits its box, or an accent that has stopped standing out. For each of those, propose the smallest fix rather than a redesign.
📌 This is also your seasonal switch. One black-and-white variable set for a serious announcement, one warm set for a launch, same layouts underneath. Save each variable block in your brand-dna.md as a named theme and you can move a whole month of content between moods in one message.
the craft

Four things that separate on-brand from generic

🎯 Real hex codes, not colour names "Warm orange" gets you a different orange every time. Six hex codes in a file gets you the same brand across fifty posts.
📐 One type scale Pick three sizes and reuse them. Ten sizes across a set is the fastest way to make finished work look improvised.
🌬️ More white space than feels right Almost every AI-generated layout is too full. Ask for the same design with 30 percent less on the canvas and compare.
✂️ One accent, one job If the accent colour is on the headline, the button and the border, it stops being an accent and the eye has nowhere to land.
⚠️ Check the copy against your own page before anything posts. Generated brand copy will cheerfully promise a guarantee you do not offer or a number you cannot back. Read every headline with your product page open beside it. This takes five minutes and it is the difference between a batch and a correction post.
make it one word

Optional: turn the chain into a /brand skill

Once you have run this a few times, stop pasting four prompts. A skill is a small folder with a SKILL.md inside holding a name, a description of when to use it, and your instructions. Claude reads the description and pulls in the full skill when your request matches, so the chain becomes one word. Skills work on every plan, Free through Enterprise, and there is no code to write.

⚡ build the brand skill 
Build me a reusable Claude skill called "brand" that runs my whole brand creative chain.

Use skill-creator to write it. The SKILL.md description should say to use it whenever I ask for on-brand social creatives, campaign concepts or a brand style guide. The instructions should say: first look for a brand-dna.md file in the project and read it, and if there is not one, ask me for a URL and build it before doing anything else. Then, when I ask for creatives, generate each one as a single self-contained HTML file at 1080 by 1350 with every brand value declared as a CSS variable in a :root block at the top, generous margins of at least 80 pixels, one focal point per canvas, and the accent colour used on one element only. Always finish a creative by listing which brand rules were applied and anything that was guessed.

Include a rule that you never invent a statistic, testimonial or guarantee that is not in the brand DNA file, and that missing information is flagged rather than filled in. Then package it as a zipped folder I can upload.
  1. 📦 Take the folder it hands you. skill-creator finishes with a folder containing a SKILL.md. That folder is the skill, there is nothing else to build.
  2. ➕ Add it to Claude. In the app, open Customize, then Skills, click Add, and choose Upload a skill to add the zip. In Claude Code, drop the folder into ~/.claude/skills/ instead. Anthropic's creating custom skills article walks the same steps.
  3. 🧪 Test it on a post you have already made. Run it against something you designed by hand so you can see where it falls short, then tell it what it missed and have it edit the SKILL.md.
be honest about it

Where this genuinely wins, and where it does not

✅ Worth building this way Quote cards, stat posts, tip lists, carousel covers, announcements, event graphics, anything typographic. These come out clean and they re-render in seconds.
🌱 Still needs a human or a camera Product photography, anything with your face in it, illustration with a specific hand-drawn style, and video. Design the frame here, drop the photo in after.

The honest ceiling is taste. Claude will apply your rules faithfully, which means a vague DNA file produces confident, consistent, mediocre design. Time spent sharpening that one file pays out across everything you build afterwards.
