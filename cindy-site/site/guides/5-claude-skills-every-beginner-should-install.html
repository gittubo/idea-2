How to install a skill

On the Claude app, go to Customize, then Skills. Hit Browse to grab ready-made skills from the gallery, or hit Add to create one with Claude, write the instructions yourself, or upload a skill file. In Claude Code, use the plugin marketplace: run /plugin marketplace add anthropics/skills, then /plugin install document-skills@anthropic-agent-skills. Skills work the same across the app, Claude Code, and the API.

The 5 to install

📄 Install this one first 
1. Document skills (pptx, xlsx, docx, pdf). The highest payoff for non-coders. Claude builds real PowerPoint, Excel, Word, and PDF files, not text you copy out. Add them from Customize, then Skills (they're in the Browse gallery).
🧬 The one that builds the rest 
2. skill-creator. The skill that builds other skills. Say "use skill-creator to build a skill that does X" and it scaffolds a custom one for you, no code.
🏗️ For when you start building 
3. Superpowers (by obra). Turns Claude Code into a disciplined builder that plans before it codes, so your first app or automation holds together. Add the obra/superpowers marketplace, then install superpowers.
📣 Pick a specific one, not a vague pack 
4. A marketing skill pack. For ad copy, SEO, and content workflows. Pick a specific one from a curated list (below) rather than a vague "marketing skills" label, since quality varies.
🏬 Where you find everything else 
5. An awesome-Claude-skills directory. Your app store for the rest. Browse the curated list and add what fits your work.
what to watch

Good to know

The official document skills are made by Anthropic (source-available, production-grade). Community skills vary, so check before you trust one with real work. You do not need Claude Code for the document skills, the normal app is enough.

How to get the most out of it

Start with the document skills, they change the most day one. Then add skill-creator so you can build your own for the niche things you do over and over. Add the marketing pack last and test it on a real task before you rely on it.
