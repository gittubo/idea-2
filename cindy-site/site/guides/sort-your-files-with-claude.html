what you need

The setup

You point Claude at a folder and paste one paragraph. You do not need to be technical, but you do need the right Claude to do it.

🤖 Claude Code The version of Claude that can actually read and move files on your computer. It runs inside a free code editor like VS Code, in a little chat panel.
💳 A paid Claude plan Claude Code needs a paid plan (Pro is about $20/mo). The regular free chat at claude.ai cannot touch your files, so this is the part that makes it work.
🗂️ Which folder? Point it at the worst offender first: your Downloads or your Desktop. That is where the 3,000-file mess usually lives.
the prompt

Paste this in

Open Claude Code in the messy folder, then paste this exactly.

🗂️ the file-sorting prompt 
Go through every file in this folder and organise it the way a tidy, organised
person would. Use your judgment to work out what each file is and where it should
sensibly live, then create clearly named folders and move everything into them.
If you are not sure where something belongs, ask me before you move it. If you
still can't tell, put it in a folder called "review me" so I can check it myself.
Don't delete anything, and don't dump files into random folders, build a structure
that actually makes sense.
run it safely

How to run it without stress

  1. 🧪 Nervous? Run it on a copy first Duplicate the folder and let Claude sort the copy, so you can see exactly what it does before you trust it with the real thing.
  2. 💬 Answer its questions honestly When it asks where something belongs, tell it. That back-and-forth is what makes the folders fit how your brain actually works, instead of a generic "by file type" mess.
  3. 🔎 Check the "review me" folder at the end Anything it was unsure about lands there, so nothing important ever gets moved without you seeing it.
  4. ↩️ Nothing gets deleted The "don't delete anything" line is the whole safety net. It only ever moves files, never removes them.
why it works

Why this beats a normal "sort my files" prompt

Most file-sorting prompts just say "sort by type," and you end up with folders that still do not help you find anything. This one tells Claude to think like an organised person, ask when it is unsure, and park the maybes in a single review folder. That is the difference between a one-time cleanup and a system you would actually keep using.

make it a habit

Reuse it every time a project wraps

Once your structure exists, keep it clean with a shorter version. Run this whenever a project finishes or the folder gets messy again.

🔁 the keep-it-tidy prompt 
Organise this folder the same way as before: use your judgment, ask me about
anything ambiguous, put the maybes in a folder called "review me", and don't
delete anything.
🌱 An hour of Sunday admin turns into about two minutes. Mine finished sorting while I made a coffee.
bonus

5 more prompts to stay organized

Once the big cleanup is done, these keep everything tidy. Same rules apply: point Claude Code at the folder, and it only ever moves or renames, never deletes.

1️⃣ rename the cryptic files 
Look through this folder for files with useless names like IMG_4821, Untitled 3,
Screenshot 2026-01-02, and document(final)(2). For each one, work out what it
actually is from its contents, type, and date, then rename it to something clear
and consistent, like 2026-01-15-invoice-figma.pdf or client-logo-final.png. Keep a
plain-text log mapping every old name to its new name so I can undo it, and don't
delete or move anything, only rename.
2️⃣ get to a clean desktop 
My desktop is my dumping ground. Move everything on it into a folder called Desktop
Archive, sorted into sensible subfolders by type and project, except for the handful
of things I clearly use every day, which you should leave in a small folder called
Active. Ask me if you are unsure whether something is active. Don't delete anything,
just get my actual desktop to nearly empty while keeping everything findable.
3️⃣ find the duplicates, safely 
Scan this folder and its subfolders for files that are exact duplicates or very
likely the same thing (same content, or near-identical names and sizes like
report.pdf and report(1).pdf). Do not delete anything. Instead give me a simple list
grouped by which files look like copies of each other, with the full path of each,
and mark which one you would keep. I will decide what to remove.
4️⃣ turn documents into a real filing system 
Organise this folder of documents (PDFs, docs, invoices, contracts) into a filing
system a tidy person would build: clear top-level folders by area, sensible
subfolders, and consistent names with dates. Then create an index file at the top
that lists what lives where and where new things should go, so the system is obvious
later. Ask me about anything ambiguous, put maybes in review me, and don't delete
anything.
5️⃣ make a convention so it stays tidy 
Based on how the files in this folder are actually used, propose one simple naming
convention and folder structure I can stick to going forward (for example
date-project-description). Explain the rule in a few plain lines, then save it as a
README file in this folder, and rename or move a few example files to show me what
it looks like in practice. Keep it simple enough that I will actually follow it.
