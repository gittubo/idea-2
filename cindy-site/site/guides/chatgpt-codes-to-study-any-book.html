How these codes actually work

ChatGPT does not have real built-in slash commands like /mindmap. There is no hidden menu. Each "code" works for one of three reasons:

  • Priming. Teach ChatGPT the codes once at the top of a chat, then just type the short label. Paste the priming line below, then you only ever type the short version.
  • A Custom GPT. Put all the code definitions in a Custom GPT's instructions once, and every code works forever without re-priming.
  • It is just shorthand. Even with no priming, typing "/cornell notes on this chapter" usually works, because ChatGPT reads the words, not a real command.
prime it once
For the rest of this chat, when I type a code starting with a slash, run the matching instruction on whatever text I give you. /mindmap means output a text mind map of the key topics. /flashcards means make question-and-answer cards. I'll add more codes the same way, then just type the short version.
How to use them. Paste the book text, a chapter, or a PDF into ChatGPT first (or just tell it the title and author for a well-known book), then type the code. The free tier handles every text output here. A few visual outputs (generated diagram images, and mermaid diagrams that render as pictures) need the image or Canvas features, flagged where they come up.
understand a book

1. Understand a book

/tldr Give me a 5-sentence summary of this book. → the fast gist.
/bigidea State the single central thesis in one sentence, then the 3 arguments that support it. → the core argument.
/chapters List every chapter with a one-line summary of each. → a chapter map.
/keytakeaways Give me the 10 most important takeaways as a numbered list. → the actionable points.
/themes Identify the recurring themes and note where each one appears. → a theme tracker.
/premise Explain the author's core assumption and whether they actually prove it. → a critical read.
/whoisitfor Describe the ideal reader and the problem this book solves for them. → context on the book.
/arc Trace how the main idea develops from the first page to the last. → the idea's arc.
/oneliner Summarize this book as one memorable sentence I could quote. → a shareable line.
/context Give me the historical and intellectual context this was written in. → the background.

Two quick catches on the visual ones. Mermaid code (/flowchart, /conceptmap) shows as an actual picture inside Canvas or a mermaid viewer, not always inline in chat, so open it in Canvas to see the diagram. And /diagramimage needs image generation on your plan; if it is not available, ask for the labeled text version instead.

save these five

5 power codes to paste in full

These are the long versions worth keeping in full. Paste your text first, then paste one of these.

/studysystem
You are my study coach. Using the text I paste, build a complete study system:
1. A one-page overview of the core idea.
2. The 10 highest-yield points, ranked by importance.
3. A glossary of every key term with a plain-language definition.
4. 15 flashcards as question and answer.
5. A 10-question practice quiz with an answer key at the end.
6. A 7-day study schedule telling me what to review each day.
Keep it clear and beginner-friendly. Ask me one clarifying question first if the material is ambiguous.
/mockexam
Act as my examiner. From the text I paste, create a timed mock exam:
Section A: 10 multiple-choice questions (4 options each).
Section B: 4 short-answer questions.
Section C: 1 essay question with a suggested outline.
Give clear instructions and a suggested time limit at the top. Put a full answer key and marking notes at the very bottom, after a line of dashes, so I can test myself first.
/socratic
Be my Socratic tutor for the text I paste. Do not lecture. Ask me one question at a time, starting simple and getting harder. After each answer I give, tell me if I am right, fill the smallest gap, then ask the next question. Track what I struggle with, and after 10 questions give me a short list of exactly what to review.
/actionplan
Turn the book I paste into a practical 30-day action plan. For each week give me: a theme, 2 or 3 specific actions I can actually do, and one way to measure progress. Base every action on the book's real advice, not generic tips. End with the single most important habit to keep after day 30.
/feynman
Teach me this concept using the Feynman technique on the text I paste. First explain it in the simplest possible language, as if to a beginner. Then point out every place the explanation is still vague or hand-wavy. Then ask me to explain it back to you in my own words, and correct me until my explanation would pass with a real beginner.
