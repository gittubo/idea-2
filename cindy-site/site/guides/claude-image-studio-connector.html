the basics

What a custom connector actually is

A custom connector lets Claude talk to an outside tool through a shared standard called MCP (Model Context Protocol). You give Claude one URL, Claude connects to that tool's server, and from then on you can ask for what that tool does in plain language. An image connector is just this pointed at an image model, so Claude can generate and edit pictures without you leaving the chat.

Two things worth knowing up front:

🧠 Claude does not draw the image itself. It writes the prompt, calls the connected image model, and shows you the result. The connector is the bridge.
🧪 It is in beta. Anthropic lists custom connectors as a beta feature, available on Free, Pro, Max, Team and Enterprise (Free is capped at one connector). Source: Claude Help Center.
the setup

The cleanest way to plug in an image model

The reel version ("just paste the Nano Banana URL") skips a real fork in the road, so here is the honest version.

The one I'd start with: Higgsfield. It is a proper paste-a-URL remote connector, and it orchestrates 15+ image models behind one connection, including Nano Banana Pro (Google's Gemini 3 Pro Image), Higgsfield Soul, Seedream, FLUX and GPT Image, up to 4K. Claude picks the best model for your brief, or you can name one. Source: Higgsfield.

Setup for Higgsfield (about 60 seconds):

  1. 🔗 Copy the connector URL: https://mcp.higgsfield.ai
  2. ⚙️ In Claude, open Customize, then Connectors. Click the + and choose Add custom connector.
  3. 📋 Name it "Higgsfield", paste the URL, click Add, then Connect and sign in with a Higgsfield account. Source: Higgsfield setup.
  4. ✅ Turn it on in a chat with the + button in the message bar, then Connectors, so Claude knows it can use it.
What about "Nano Banana" specifically? Nano Banana is Google's nickname for its Gemini image models (Nano Banana = Gemini 2.5 Flash Image, Nano Banana Pro = Gemini 3 Pro Image). Source: Google DeepMind. You reach Nano Banana Pro through Higgsfield above. There is also a separate community server called Nano Banana MCP, but that one is a local install you run yourself with your own Google API key (claude mcp add nanobanana -e NANOBANANA_API_KEY=your-key -- npx @cubancodepath/nanobanana-mcp), not a simple paste-a-URL connector, so it is the power-user path, not the beginner one. Source: Nano Banana MCP.

The prompts I actually paste

Once a connector is live, you brief Claude like a creative director, not a machine.

🎨 one hero image 
Using Nano Banana Pro, create an image of a man sprinting on a running track at golden hour, shot on a long lens, shallow depth of field, warm cinematic light, 4:5 for Instagram.
📚 the batch set 
Here are 10 angles for my product (front, 45 degrees, top-down, in-hand, on a desk, lifestyle kitchen, close-up texture, flat lay, on a plinth, held up to window light). Generate all 10 as a consistent set: same product, same soft daylight, cream background, 1:1. Keep the look identical across every shot.
✏️ edit in place 
Take that last image and make three edits: one with the background swapped to a warm cafe, one with cooler blue lighting, and one zoomed in on the product. Keep the product itself exactly the same across all three.
the payoff

Where this genuinely saves you time

  • 📚 Batching. Instead of prompting one image at a time, you hand Claude a list and it fires off the whole set in one message. This is the real unlock for product shots, thumbnail options, or ad variations.
  • 🎭 Consistency. Because Claude holds the thread, you can say "keep the same character" or "same product, new scene" and it carries the look across a whole set, which is exactly what breaks when you re-prompt from scratch in a separate app.
  • ✏️ Edit in place. Swap a background, change the lighting, or restyle without re-uploading, because the image is already in the conversation.
the craft

How to get the most out of it

  • 🌱 If you're new: start with Higgsfield's paste-a-URL connector and let Claude choose the model. Describe the mood and the use ("warm, cosy, for Instagram, 4:5") rather than camera jargon, and Claude fills in the rest.
  • ⚡ If you're a power user: name the model per job (Nano Banana Pro when you need legible text baked into the image, since it is the strongest at in-image text per Google), and ask Claude to run the same prompt across two models side by side so you can compare before committing credits.
what to watch

Honest heads-up

  • 💳 It is not free forever. The connector plugs into a paid image service, so generations draw on that tool's credits or your own API key. Nano Banana Pro's free tier is limited before it drops you back to the standard model. Source: Google.
  • 🧪 Beta means occasional wobbles. Connectors are still in beta, so if a generation stalls, re-enable the connector in the chat's + menu and try again.
  • 💻 On Claude Code, use the CLI, not the Settings dialog, to add the server. The paste-a-URL flow is for claude.ai, Desktop and mobile.
