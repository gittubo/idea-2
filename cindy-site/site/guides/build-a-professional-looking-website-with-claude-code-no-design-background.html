The one skill to add

If you just ask Claude to build a site, it looks generic. A design skill fixes that by giving Claude proper typography, colour, and layout rules.

🎨 Give Claude a designer's eye 
Install UI/UX Pro Max (a free, open-source skill): paste its link into Claude Code and say "install this skill." Link: github.com/nextlevelbuilder/ui-ux-pro-max-skill

Then plug in 21st.dev Magic, a free MCP that generates polished, pre-built UI components and animations, so Claude drops in finished pieces instead of building every button from scratch.

🧩 Add pre-built components (21st.dev Magic MCP) 
Connect the 21st.dev Magic MCP in Claude Code (from magic.21st.dev), then say: "use Magic to add a modern hero section and a pricing table," and Claude pulls in ready-made components you can tweak to your brand.
the flow

The build workflow

1 · Brief it properly 
Describe the site in detail: "Build a one-page site for my coaching offer. Audience: busy founders. Sections: hero, 3 benefits, testimonial, pricing, FAQ, sign-up. Vibe: warm and premium. Brand: cream #FAF7F2, terracotta #D97757, Averia headings, Poppins body." Detail drives quality.
2 · Fix it by talking, not clicking 
Preview and refine by talking: Claude runs a live preview, then you say "tighten the spacing", "make the hero bolder", "add a subtle fade on scroll", until it is right.
3 · Get it live for free 
Deploy free: drag the finished folder onto Netlify Drop (netlify.com) and you have a live site, no Git or command line needed.
the craft

What makes it look high-end

Consistent typography and a real type scale, generous whitespace, a coherent colour system instead of random colours, a little tasteful motion, and most of all real content. Placeholder text is the number one thing that makes a site look cheap.

what to watch

Good to know

It still needs your taste and editing, and the "$10k in 10 minutes" framing is hype. What is true: you can get a properly professional marketing or portfolio site fast and free, then keep refining it.

How to get the most out of it

Write your real copy first, then have Claude design around it, that alone puts you ahead of most AI sites. Give brand colours and fonts in the prompt so it comes out on-brand, and refine in small, specific steps rather than one giant ask.
