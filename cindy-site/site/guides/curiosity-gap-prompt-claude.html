The curiosity gap prompt: fix a hook that gets skipped

the real problem

Your hook is not the thing that is broken

When a reel gets skipped at second two, the usual fix is to rewrite the first line ten times. That almost never works, because the first line is only a symptom. A hook cannot create interest out of nothing. All it can do is point at something interesting that is already sitting in your script. If the script has nothing worth waiting for, no opening line saves it, and a borrowed template makes it worse: a first line that a thousand other accounts have used reads as an ad, and people scroll past ads without thinking about it.

So the order most people use is backwards. Do not write a hook and then find a video for it. Find the gap in your script first, then let line one open it.

👩‍💻 Why this is worth the ten minutes. Instagram says the strongest predictions it makes about a reel include how likely you are to reshare it and how likely you are to watch it all the way through (Instagram, ranking explained). Both of those are downstream of one thing: does the viewer need to know what happens next.
the concept

What a curiosity gap actually is

The idea is older than short-form video. The psychologist George Loewenstein described curiosity as an information gap: a felt difference between what you know and what you want to know. Curiosity spikes when the gap is small and specific, not when it is huge and vague, and it fades entirely when you either know nothing about the subject or already know the answer (Loewenstein, The psychology of curiosity, Psychological Bulletin, 1994).

Which is exactly why "5 tips to grow on Instagram" does nothing. There is no gap. The viewer already knows the shape of the answer. These four gap types do work, because each one leaves a specific hole open:

🧠 The named unknown You name a thing the viewer has clearly experienced but has never had a word for. "There is a reason your reels die at second two and it is not your delivery." They stay to get the name.
🌱 The broken assumption You state that something they already believe is wrong, and you are specific about which part. "Copying viral hooks is what is getting you skipped." They stay to defend the belief.
💡 The visible outcome, hidden method You show the after and withhold the how. Screen recording of the finished thing, then "I built this in one sitting." They stay for the method.
👩‍💻 The unfinished count You promise a specific number and give away one immediately. "Two ingredients. Here is the first." Counting is the cheapest open loop there is, so use it sparingly and always deliver.
🌱 Notice what none of these do: they do not withhold something the viewer never wanted. A gap only pulls if the viewer already cares about what is on the other side of it. That is the whole test.
the workflow

The 10-minute audit, start to finish

  1. 📄 Open a normal Claude chat. Go to claude.ai or the Claude desktop and mobile apps and start a fresh chat. The free plan is enough for all five prompts below. If you want the audit to remember your voice and your niche across scripts, make a Project instead and drop your last five scripts in as project knowledge (how projects work).
  2. 📋 Paste the FULL script, not the hook. This is the step everyone skips. Claude cannot find a gap in a first line, because the gap lives in the payoff. Paste the entire thing, filler and all, exactly as you would say it.
  3. 🔎 Run prompt 1, the gap audit. It tells you the one question your video answers, where the script gives that answer away, and how strong the gap is out of 10. Read this before you write a single new line.
  4. ✍️ Run prompt 2, the rewrite. Only after the audit. It writes line one so the gap opens and stays open, in your voice, with the answer withheld.
  5. 🧪 Run prompt 3, the stranger test. A fresh chat, no context, judging line one cold. If a stranger does not need to know what happens next, you are not done, and now you know it before you film instead of after you post.
  6. 🩹 If there was no gap, run prompt 4. A missing gap is a script problem. Prompt 4 rebuilds the script around one instead of decorating a flat script with a clever opener.
copy this one first

Prompt 1: the curiosity gap audit

This is the one from the reel. Paste your whole script where it says to, then send.

🔎 find the curiosity gap 
Here is the full script for a short-form video. Read all of it before you respond, and do not rewrite anything yet.

[paste your entire script here, every line, exactly as you would say it]

Act as a retention editor, not a copywriter. Start by telling me in one plain sentence the single question this script actually answers for a viewer, and if it tries to answer more than one, name them all and tell me which is strongest. Then find the moment the script gives that answer away: quote the exact line, say roughly which second it lands on if the whole thing is read at speaking pace, and tell me how much of the video is left after that point. Then score the gap out of 10 on three separate things, with one sentence of reasoning each: how specific the question is, how much a stranger already wanted that answer before they met me, and how long I make them wait for it. Be blunt about low scores. Finish with the single structural change that would widen the gap the most, described as a change to the script, not to the first line.
💡 Read the "answers it away" line carefully. Nine times out of ten the problem is that line three of the script hands over the payoff, so the rest of the video is a recap. Moving that line to the end fixes retention faster than any hook rewrite.
then this

Prompt 2: rewrite line one so it opens the gap

Send this in the same chat, straight after the audit, so Claude still has your script and the gap it found.

✍️ open the gap, do not answer it 
Now write line one only, using the gap you just identified. Give me 8 options and nothing else, no preamble and no explanation between them.

Rules for every option: it must point directly at the question the script answers without containing any part of the answer, it must be speakable out loud in under three seconds, and it must use plain words a friend would use rather than marketing language. Ban these openings completely: "here is how to", "the secret to", "nobody talks about", "POV", and anything that starts with a number of tips. Two of the eight must be a flat statement that breaks an assumption, two must name a feeling the viewer has had but has no word for, two must be a specific observation about a thing they have already noticed, and two are your own choice. Under each option, add one short line telling me exactly which unanswered question that opening leaves in the viewer's head. If an option leaves no question open, delete it and write another.
the check

Prompt 3: the stranger test

Open a brand new chat for this one. It only works if Claude has never seen your script, because you are simulating someone who has never seen it either.

🧪 judge it cold 
You are a stranger scrolling Instagram at 11pm, half tired, thumb already moving. You have never heard of me and you do not follow me. I am going to give you only the first line of a video, with no context at all.

Read it once, at scrolling speed, then answer four things in order. One: in your own words, what question is now sitting in your head, if any. Two: on a scale of 1 to 10, how badly do you need that question answered right now. Three: would you keep watching, or keep scrolling, and say which one honestly rather than encouragingly. Four: if you would scroll, name the exact word or phrase that made you lose interest. Do not be polite about it and do not suggest improvements unless I ask.

The line is: [paste your new line one here]
👩‍💻 A 6 out of 10 is a fail, not a pass. The bar is "needs to know", not "mildly interested". Run prompt 2 again with the feedback rather than talking yourself into a line you already know is soft.
when there is nothing to find

Prompt 4: rebuild a script that has no gap

If the audit could not name a single clear question, that is the useful result. It means the video is a list of things you know rather than an answer to something someone wanted. Fix the script, not the hook.

🩹 build the gap into the script 
The audit found no clear curiosity gap in this script, so I want to rebuild it around one instead of patching the opening.

Here is the topic and who it is for: [topic] for [the exact person, for example "marketers who have never used AI for ad copy"]. Here is the one useful thing I actually know that they probably do not: [your real insight, in plain words, even if it sounds obvious to you].

Give me three different gap-first structures for this video. For each one, write the question the whole video exists to answer, the specific moment I am allowed to answer it (as a fraction of the video, for example "at 80 percent"), the three or four beats that come before that answer and what each beat withholds, and the payoff line itself. Then tell me which of the three has the most tension for a viewer who does not already follow me, and why. Keep every beat something I could actually say out loud in one breath.
do not skip this

Close the loop, every time

A curiosity gap is a promise. Open one and refuse to close it and you get a great three-second retention curve and an audience that stops trusting you by the fourth video. The rule I hold myself to: whatever line one implies, the video answers it fully, on camera, before the CTA. The DM resource is extra depth, never the missing answer.

💡 If your only payoff is "comment KEYWORD for the answer", the video is an ad for a resource, and viewers can feel it. Give away the actual method in the video and let the resource be the longer version.
make it permanent

Turn the audit into a reusable Claude skill

If you script more than once a week, stop pasting prompt 1 by hand. A skill is a small folder with one file in it that teaches Claude your process once, then triggers itself whenever you ask for it. Skills work on every plan, Free through Enterprise.

  1. ✍️ Ask Claude to build it. Paste the prompt below into any Claude chat. It writes the whole skill file for you, no code involved.
  2. 📦 Get it zipped. Ask for the finished skill as a zipped folder so it is ready to upload. It will contain a single SKILL.md with a name, a description that decides when it triggers, and your audit steps.
  3. ➕ Upload it. In the Claude app or on the web, open Customize, then Skills, then Add, then Upload a skill, and choose the zip. In Claude Code, drop the folder into ~/.claude/skills/ instead. Full steps: creating custom skills.
  4. 🔁 Use it. From then on, paste a script and say "run my gap audit". Claude runs all three passes in order without you re-explaining anything.
👩‍💻 build the gap-audit skill 
Build me a reusable Claude skill that runs a curiosity gap audit on any short-form video script I paste.

Write the SKILL.md yourself. Give it a short lowercase hyphenated name with no "claude" or "anthropic" in it, and a description that says both what it does and when to use it, because that description is what makes you trigger it on your own. The instructions inside should run three passes in order: first find the single question the script answers and the exact line that gives the answer away, then score the gap out of 10 for specificity, pre-existing viewer desire, and delay before payoff, then write 8 options for line one that open the gap without answering it. Tell the skill to refuse to write hook options if it could not find a gap, and to tell me the script needs rebuilding instead. Before you write it, ask me the three or four questions you need about my niche, my usual video length, and my voice. When you are done, package it as a zipped folder and tell me exactly how to upload it.
