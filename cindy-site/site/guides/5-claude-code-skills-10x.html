The idea in one line

Most skills teach Claude one job. These five upgrade the session itself: how Claude finds tools, plans work, remembers you, judges design, and learns from your corrections.

the stack

1. find-skills (the librarian)

  • 🔎 What it does: you tell Claude what you are building and it searches the open skills directory, shows the best matches, and installs them for you. It is the most installed skill on the entire skills.sh leaderboard (2.5M installs).
  • 💻 Install: run npx skills add vercel-labs/skills@find-skills in your project folder.
  • ✨ Try this prompt after installing: "Find me a skill for writing Instagram carousels, show me the top options before installing."
  • 🔗 Link: github.com/vercel-labs/skills (directory: skills.sh)

2. Superpowers (the planner)

  • 🧭 What it does: it makes Claude brainstorm with you, write a real plan broken into small verifiable tasks, and test its own work before touching your project. It is a full development methodology by Jesse Vincent, and it is where most rework disappears.
  • 💻 Install: inside Claude Code run /plugin install superpowers@claude-plugins-official.
  • ✨ Tip: give it something meaty (a new feature, not a typo fix) to see the brainstorm-then-plan behaviour kick in.
  • 🔗 Link: github.com/obra/superpowers

3. claude-mem (the memory)

  • 📝 What it does: it captures what happens in your session, compresses it with AI into searchable summaries, and injects the relevant context back into your next session. Tomorrow's Claude opens already knowing your project (87k+ GitHub stars, works with Claude Code and other agents too).
  • 💻 Install: run npx claude-mem install, then restart Claude Code.
  • ✨ Test it: end a session, open a new one, and ask "where did we leave off yesterday."
  • 🔗 Link: github.com/thedotmack/claude-mem (docs: docs.claude-mem.ai)

4. Impeccable (the design taste)

  • 🎨 What it does: it gives Claude a real design vocabulary plus 46 hard detector rules that catch AI design cliches (nested cards, default gradients, template layouts) before they ship. Built by Paul Bakaus, the creator of jQuery UI, and it grew out of Anthropic's own frontend-design skill.
  • 💻 Install: run npx impeccable install in your project, then /impeccable init inside Claude Code.
  • ✨ Try this: run /impeccable audit on a page you already built and watch what it flags.
  • 🔗 Link: github.com/pbakaus/impeccable (creator bio: paulbakaus.com)

5. task-observer (the self-improver)

  • 👀 What it does: it watches your sessions for corrections you make, gaps in your current skills, and repeated workflows, logs them, then drafts improvements to your other skills. You review and approve the changes, so your setup compounds and you stay in control. By Eoghan Henn (Rebelytics), open source under CC BY 4.0.
  • 💻 Install: there is no one-line installer. Download the skill file (SKILL.md), the README, and the user guide from the repo, drop them into your project, and ask Claude to set it up for your workflow.
  • ✨ Habit that makes it work: once a week, ask Claude to show the observation log and approve the upgrades you like.
  • 🔗 Link: github.com/rebelytics/one-skill-to-rule-them-all
in this order

The order I would install them in

  1. 🥇 claude-mem first, so everything you do from today carries forward.
  2. 🥈 Superpowers second, so big tasks stop needing rework.
  3. 🥉 find-skills third, so you never manually hunt for a skill again.
  4. 🎯 Impeccable when you next touch anything with a front end.
  5. 🔁 task-observer last, once you have a week of real sessions for it to learn from.
