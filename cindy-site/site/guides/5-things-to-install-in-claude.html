the five from the reel

The five, with what each one actually does

All five are free. Three are single skills you drop in, two are whole libraries. Install instructions are the same for every one of them, and they are in the next section.

  1. 1 · frontend-design Anthropic's own design skill. It ships inside the official skills repo rather than being its own project, so there is no separate star count to quote. anthropics/skills
    Careful: a bare search for "frontend-design" lands on an unrelated third-party repo. Use the official one.
  2. 2 · marketingskills · 52k stars 50 marketing skills covering CRO, copywriting and SEO. The real folder names are content strategy, copywriting and copy editing. coreyhaines31/marketingskills
  3. 3 · Superpowers · 294k stars The skills framework most of the others copy. It makes Claude plan, build and review its own work instead of one-shotting. obra/superpowers
  4. 4 · hyperframes · 55k stars Write HTML, get a rendered video. Built by HeyGen for agents rather than for humans clicking a timeline. heygen-com/hyperframes
  5. 5 · Impeccable · 73k stars A design language that stops whatever Claude builds from looking obviously AI-made. pbakaus/impeccable
⚠️ The step people miss. After you drop a skill in, you have to actually turn it on. In claude.ai that is Customize, then Skills. If you skip it the skill sits there doing nothing and it looks broken.
do this once

How to install any of them

Two routes. Both free, pick whichever matches where you work.

  1. 1 · In claude.ai Go to Customize, then Skills, then add the skill. Turn it on before you test it. claude.ai/customize/skills
  2. 2 · In Claude Code Clone or download the repo into your skills folder, then restart the session so it gets picked up. the official skills repo
🌱 Install one, use it for a week, then add the next. Five new skills on day one means you will not notice which one is doing the work.

the honest bit

Two things worth knowing

  1. 1 · A skill is instructions, not magic It changes how Claude approaches a job. If your prompt is vague the skill cannot save it. where skills live
  2. 2 · Star counts move Every number here was read on 2 October 2026. They are a floor. If a repo has gone quiet for a year, that matters more than the number. check any repo's last commit
