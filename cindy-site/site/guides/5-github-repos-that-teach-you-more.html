the five from the reel

Over a million stars between them

These five have more than 1,000,000 stars between them, all free, no sign-up, no email gate. The order below matters more than the list does.

  1. 1 · Build your own X · 551k stars Rebuild Git, Docker, Redis or a database from scratch, following someone who already did it. The single best way to stop being scared of a codebase. build-your-own-x
  2. 2 · Project-based learning · 285k stars Build-something tutorials sorted by language, for when you learn by making rather than reading. project-based-learning
  3. 3 · ML for Beginners · 91k stars Microsoft's free 12-week, 26-lesson machine learning course, with quizzes and real assignments. microsoft/ML-For-Beginners
  4. 4 · 30 Days of Python · 75k stars A day-by-day Python challenge from nothing to competent. Start here if you cannot yet write Python. 30-Days-Of-Python
  5. 5 · 500 AI projects with code · 37k stars 500 machine learning, deep learning, computer vision and NLP builds, each with working code rather than just an idea. 500 AI projects
the order

Where to actually start

Doing these in list order is how people quit in week two. This is the order that works.

  1. 1 · If you cannot write Python yet, start at 30 Days Everything else assumes you can read code. Do not skip this to get to the interesting one. 30 Days of Python
  2. 2 · Then Project-based learning, one project only Pick a single project in a language you want. Finish it. One finished thing teaches more than four abandoned ones. pick one
  3. 3 · Then Build your own X when you want to understand the tools This is the one that changes how you read other people's code, because you have built a small version of the thing. build-your-own-x
  4. 4 · ML for Beginners if you want the theory properly It is a real course with a real syllabus, so treat it like one and do the assignments. the course
  5. 5 · 500 AI projects as a reference, not a reading list Use it to find a build near what you want, then read that one. Nobody works through 500 of anything. the index
the honest bit

Why free beats paid here, and where it does not

  1. 1 · Free beats paid on content Microsoft's course is the same material a bootcamp repackages. The content is not the thing you are short of. see for yourself
  2. 2 · Paid beats free on accountability What a course sells is a deadline and someone to ask. If you have never finished a free one, that is the gap, not the material. the 30-day format helps with this
