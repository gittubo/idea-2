the mental model

What a plugin actually is

A Claude Code plugin is a bundle of skills, agents, hooks, and connections that installs with one command and changes how Claude works for you. Marketplaces are just GitHub repos that list plugins, and Anthropic runs the official one. Full mechanics are in the official docs: code.claude.com/docs/en/plugins

The 5 plugins

write less code

1. Ponytail (Claude writes less code)

  • 🔗 Repo: github.com/DietrichGebert/ponytail
  • 🦥 What it does: makes Claude behave like the laziest senior dev in the room. It questions whether code needs to exist at all, reaches for the standard library before custom code, and prefers one line over fifty.
  • 📊 The honest numbers: the repo's own benchmark (12 real Claude Code feature tasks on a FastAPI + React template, run with and without the skill) reports about 54% less code, roughly 20% cheaper, and about 27% faster. Those are the maintainer's published numbers, not an independent study, and the gains shrink when your code is already minimal. Source: the benchmark section of the repo above.

Install (run as two separate commands in Claude Code):

🦥 Two separate commands 
/plugin marketplace add DietrichGebert/ponytail
/plugin install ponytail@ponytail
stop starting over

2. claude-mem (memory across sessions)

  • 🔗 Repo: github.com/thedotmack/claude-mem
  • 🧠 What it does: hooks into your session lifecycle, compresses everything Claude did into searchable summaries, and injects the relevant context back the next time you open Claude Code. Your project stops resetting to zero every morning.
  • 🔒 Nice touch: wrap anything in private tags and it stays out of memory.

Install:

🧠 One line, then restart 
npx claude-mem install
your second brain

3. The Obsidian skill (a second brain Claude maintains)

  • 🔗 Repo: github.com/kepano/obsidian-skills
  • 🗂️ What it does: teaches Claude the real Obsidian formats (linked notes, Bases databases, Canvas boards, plus the Obsidian CLI), so Claude can write, link, and file notes in your vault properly instead of dumping plain text.
  • 👤 Who made it: Steph Ango, Obsidian's CEO (source: stephango.com/about), which is about as first-party as a community skill gets.

Install (drop the repo's contents into a .claude folder at the root of your Obsidian vault, or add it as a plugin):

🗂️ Teaches Claude your vault formats 
/plugin marketplace add kepano/obsidian-skills
/plugin install obsidian@obsidian-skills
catch the real bugs

4. Code review (official, 4 reviewers in parallel)

  • 🔗 Docs: github.com/anthropics/claude-plugins-official (code-review README)
  • 🔍 What it does: adds a /code-review command that launches 4 independent agents in parallel (2 check your project guidelines, 1 hunts obvious bugs, 1 reads git history for context), then scores every finding 0-100 for confidence and throws away anything under 80. You see real issues, not nitpicks.

Install:

🔍 Official, no marketplace needed 
/plugin install code-review@claude-plugins-official
browse the rest

5. The official plugin directory (your app store)

  • 🔗 Repo: github.com/anthropics/claude-plugins-official
  • 🏬 What it is: Anthropic's curated, official directory of high-quality plugins. Internal ones (built by Anthropic) live in /plugins, community ones in /external_plugins. It registers automatically the first time you start Claude Code, so it works out of the box (per code.claude.com/docs/en/plugins).
  • 🧭 How to browse: type /plugin in Claude Code and open Discover, or install anything directly.

Install any listed plugin:

🏬 Swap in any name from the directory 
/plugin install {plugin-name}@claude-plugins-official
what to watch

Read this before you install

⚠️ Anthropic's own warning on the directory: make sure you trust a plugin before installing it, because Anthropic does not control what third-party plugins include or verify they will keep working. Skim a repo before you add it, and start with the official directory if you want the safest path.
🔄 Star counts and version numbers in the reel were checked on 13 July 2026 and move fast, so expect the repos to look even bigger when you visit.
