What a plugin actually is

A Claude plugin is two things wrapped into one install: a set of skills (pre-written instructions for a job, like planning a campaign or reviewing a contract) plus the app connectors that job needs (Notion, HubSpot, your calendar, and so on). Turn one on and Claude stops being a blank assistant and starts acting like a marketer, a salesperson, or a finance person, with the right tools already wired in. They're free, open source, and built by Anthropic. The full set lives in the anthropics/knowledge-work-plugins repo.

turn them on

Install one in about 2 minutes

  1. 🖥️ In Claude (Cowork or the app). Go to Customize → Plugins → Browse plugins, find the one that matches your work, and click Install. It activates automatically, the skills fire when they're relevant. Step-by-step with screenshots is in the Claude plugins help center.
  2. 👩‍💻 On Claude Code (the power path). Add the Anthropic marketplace first, then install any plugin by name:
claude plugin marketplace add anthropics/knowledge-work-plugins
claude plugin install marketing@knowledge-work-plugins
Swap marketing for sales, legal, productivity, or finance to install a different one. You only add the marketplace once.

The 5 to install first

These are the five I'd reach for if you actually work for a living. Each card is what it does plus the apps it plugs into, straight from the repo.

📣 Marketing Drafts content in your brand voice, plans campaigns, and reports on performance. Connects to Canva, Figma, HubSpot, Notion, Klaviyo, Ahrefs, SimilarWeb, Amplitude.
🤝 Sales Researches every prospect, drafts your outreach, preps you for calls, and builds competitive battlecards. Connects to HubSpot, Close, Clay, ZoomInfo, Notion, Fireflies.
⚖️ Legal Reads a contract or NDA, triages it, flags risky clauses, and helps you navigate compliance before you sign. Connects to Box, Egnyte, Jira, Microsoft 365.
✅ Productivity Scans your tasks, calendar, and chats so nothing slips, and runs your daily workflows. Connects to Slack, Notion, Asana, Linear, Jira, Monday, ClickUp.
💸 Finance Reconciles accounts, preps journal entries, drafts financial statements, and helps you run month-end close. Connects to Snowflake, Databricks, BigQuery, Slack.
➕ There's more The same marketplace also has data, product management, customer support, and enterprise search plugins. Browse the full 11 in the repo and pick your lane.

Two prompts to make it click

Not sure which one is yours? Let Claude pick based on your actual week:

🧭 which plugin should I install first 
Here is what my work actually looks like week to week:
[describe your role and the 3-4 tasks that eat the most time, e.g. "I run marketing for a small brand: writing posts, planning campaigns, and pulling performance numbers from different tools."]

From the Anthropic knowledge-work plugins (marketing, sales, legal, productivity, finance, data, product management, customer support, enterprise search), tell me the ONE to install first and why, the top 2 tasks it would take off my plate this week, and which of my existing apps it would connect to. Then give me a simple first task to run to test it.

Once it's installed, hand it a real job instead of asking it a question:

🚀 put the plugin to work 
You have my [marketing / sales / productivity] plugin turned on. Here is the real task:
[paste the actual thing, e.g. "Plan a 2-week launch campaign for my new guide" or "Research this prospect and draft a first outreach email: [details]"]

Use the plugin's skills. Ask me for anything you're missing before you start, then do the work and show me the draft so I can approve or edit it.
Only keep the plugins you're actively using switched on. Every active plugin takes up context, and running five at once can make Claude fuzzier, not smarter. Turn one on for the task, then turn it off.
