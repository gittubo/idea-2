The repo

👉 github.com/zubair-trabzada/ai-marketing-claude (free, MIT licensed)

what's in the box

What you're actually installing

It's not an app. It's a set of plain files that teach Claude Code marketing:

  • 🗂 15 skills: step-by-step playbook files. When you type a /market command, Claude opens the matching playbook and follows it (the full menu is in the readme)
  • 🤖 5 agents: separate Claude workers that run at the same time, each grading its own lane (they live in the agents folder)
  • 🐍 4 Python helper scripts and 6 ready-made templates (welcome emails, launch checklist, client proposal) that the skills pull in when they need them (browse them in the repo)

Everything installs at the user level into ~/.claude, so the commands work in any folder you open Claude Code in (that's exactly what install.sh sets up).

the setup

The one-paste install

  1. 💻 Get Claude Code: the terminal app or the official VS Code extension (docs here). It runs on a Pro or Max plan, or API credits
  2. 📋 Copy the command below and paste it into your terminal
  3. ♻️ Start a new Claude Code session, then type /market and pick a command
🛠 The one-line install 
curl -fsSL https://raw.githubusercontent.com/zubair-trabzada/ai-marketing-claude/main/install.sh | bash

That is the exact command from the repo readme. Prefer to read code before you run it (fair)? Clone it and run the installer yourself instead:

🔎 The read-it-first route 
git clone https://github.com/zubair-trabzada/ai-marketing-claude.git
cd ai-marketing-claude
./install.sh

Two small extras: the one-paste route uses git under the hood (install.sh clones the repo for you, so git needs to be installed), and PDF reports need one Python package: pip install reportlab (noted in the readme).

five lanes

Meet the team

Five agents, five lanes, all running at once (full specs in the audit skill):

  • ✍️ market-content: headline clarity, value proposition, copy persuasion, social proof, brand voice
  • 🛒 market-conversion: CTA effectiveness, form friction, trust signals, mobile experience, pricing page design
  • 🥊 market-competitive: positioning clarity, differentiation, how your pricing sits against rivals, third-party reputation
  • ⚙️ market-technical: title tags, meta descriptions, page speed, schema markup, Core Web Vitals
  • 📈 market-strategy: business model clarity, pricing strategy, growth loops, retention signals, upsells
the whole menu

The full menu (all 15 commands)

Straight from the readme. Start with audit and quick, the rest are specialists:

  • 🩺 /market audit <url>: the full audit, all 5 agents in parallel
  • ⚡ /market quick <url>: a 60-second marketing snapshot
  • ✏️ /market copy <url>: rewrites your copy with before and after examples
  • 📬 /market emails <topic>: complete email sequences
  • 🗓 /market social <topic>: a 30-day social media content calendar
  • 📣 /market ads <url>: ad creative and copy for every platform
  • 🌀 /market funnel <url>: sales funnel analysis and optimization
  • 🕵️ /market competitors <url>: a competitive intelligence report
  • 🛬 /market landing <url>: landing page conversion (CRO) analysis
  • 🚀 /market launch <product>: a product launch playbook
  • 🤝 /market proposal <client>: a client proposal generator
  • 📄 /market report <url>: the full marketing report as markdown
  • 🖨 /market report-pdf <url>: the same report as a polished PDF
  • 🔍 /market seo <url>: an SEO content audit
  • 🎨 /market brand <url>: brand voice analysis and guidelines
run it now

Your first 10 minutes

  1. 📂 Open Claude Code in any folder and run /market audit yourwebsite.com on your own site first
  2. 👀 Watch the fetch: it pulls your homepage plus up to 5 key pages (pricing, about, product, blog, contact), then launches the 5 agents in parallel (how the audit works)
  3. 🧮 Read the score: six weighted categories (content 25%, conversion 20%, SEO 20%, competitive 15%, brand and trust 10%, growth and strategy 10%) roll into one score out of 100 with a letter grade, A at 85 and up, down to F below 40 (the exact rubric)
  4. ✅ Jump straight to the quick wins: the report lists 5 to 10 fixes you can ship in under a week, then 3 to 7 bigger strategic moves. Pick the top 3 quick wins and make them this week's to-do list
  5. 💾 Your full report saves as MARKETING-AUDIT.md in that folder. Want it client-ready? /market report-pdf <url> turns it into a PDF (this is the one that needs reportlab)

And the obvious freelancer play: run the audit on a prospect's site and the graded report becomes the pitch. That's what /market proposal and /market report-pdf are sitting there for.

Honest notes before you run it

💳 The repo is free, the engine isn't: Claude Code runs on a Pro or Max plan, or API credits (claude.com)
🎲 Scores vary run to run: the grades are Claude's judgment against a rubric, not a deterministic crawler, so treat a 66 and a 72 as the same signal and read the recommendations, not just the number
🧪 The Calendly 69/100 in the readme is the author's demo output, not a live benchmark (see it in the readme)
